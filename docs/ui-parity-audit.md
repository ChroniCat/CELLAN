- ⛔ Power Query、3D 模型、图标库、SmartArt、屏幕截图、墨迹/绘图工具、Copilot/推荐图表、地图图表
- ⛔ 日程表（时间线切片器）：需要透视表的日期轴缓存（pivotCache 的日期维度 + 时间线部件），
  当前透视表模型是「一次生成静态结果」，没有可承载它的轴，不做同名替代。
- ⛔ 翻译：Excel 的翻译走联机服务（Microsoft Translator），本机无可用离线翻译引擎，
  不做「假装能翻译」的入口。
- ⛔ 多窗口一类（新建窗口 / 全部重排 / 并排查看 / 同步滚动 / 重设窗口位置 / 切换窗口）：
  单实例单窗口产品形态，不做同名替代（并排比较能力在「视图→并排比较」里已有，那是同窗双栏）。
- ⛔ 注释（线程化注释）：需要 `xl/persons/person.xml` + `xl/threadedComments/*.xml` 一整套
  「人 + 回复串」部件，且与批注的旧格式要双向兼容；现有批注模型是单条文本，承载不了回复串。

## 处理口径（默认执行 B）

- 对 6 类 ⛔ 项：不保留灰显假入口，从功能区移除；本文档保留记录，避免以后误以为漏做。
- 其余本地可实现项按页签继续补齐，每项必须有真实行为或明确的数据模型。
