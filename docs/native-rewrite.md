
### 第五十八轮：商用级视觉体系重构——原生屏幕字体栈、现代模态框规范与首页插画化重做（2026-11-19）

目标：彻底消除弹窗与首页残留的「早期 WinForms 细黑铁丝框 / 粗体糊墨 / 首页骨架屏线框感」，对齐成熟商用桌面软件（Fluent 2 / 飞书 / Linear）的设计品质。

- **屏幕字体栈与 `Medium` 字重体系**：`install_fonts` 按需挂载并进程级缓存 Windows 原生 `Segoe UI` + `Segoe UI Semibold (600)` + `Microsoft YaHei UI`（`msyh.ttc` 1 号 UI 专用字面，缺失时回落内嵌 Inter + 思源黑体）；新增 `ui-medium` 字族与 `ui_kit::paint_medium`（拉丁采用真 600 Semibold，中文叠加 0.38px 轻墨亚像素增重），替代小字号（12~15px）下笔画发闷粘连的 `700 Bold`，并清除弹窗中的 `11.5pt` 半像素字号。
- **全局控件与模态框（`ui_kit`）重构**：
  - 告别深灰铁丝框：默认控件边框由 `rgb(171,169,167)` 收敛为柔和浅灰蓝 `#D6DAE0`，圆角统一为 `6px`，输入框底色改为 `#F9FAFB` 并配 `BRAND_NAVY` 聚焦外发光圈（`ui_kit::text_input`，34px 高度 + 10px 内边距）。
  - 主次按钮正位：`primary_button` 由空心绿线框改为 **84×32 实心主题绿填充 + 白字**，`secondary_button` 严格同高同宽（`84×32` 白底细边），新增 `footer_split` 支持左辅右主双栏底栏，并把残留裸 `ui.button("取消/关闭")` 的对话框一并纳入统一底栏。
  - 模态框质感升级：`Dlg::show` 增加 `rgba(15,23,42,36)` 半透明背景遮罩压暗底层密集网格线；窗口升级为 `10px` 圆角、28px 柔光投影、`42px` 纯白顶栏、内嵌 `28×28` 圆角关闭按钮，内容区控件默认高度由压抑的 `20px` 提升至舒适的 `26px`。
- **「账户与本机身份」及「关于 LANCell」重做**：账户弹窗顶部增加 `#F8FAFC` 身份名片卡（深海蓝光环头像 + `本机身份 · 免登录` 翠绿胶囊徽标），底部左侧收纳无边框品牌入口 `关于 LANCell v1.70`，右侧锚定等高 `[取消] [保存]`；关于窗口升级为品牌横幅卡 + 双列立体键帽快捷键表。新增 `SC_OPEN_DLG=account|about` 无界面截图验收钩子。
- **首页（`home_page`）彻底重做**：
  - 去掉左栏顶部与窗口标题栏重复的第二枚品牌头，改为清爽的「工作区」导航侧栏 + 底部可点击的版本/关于名片卡。
  - 四张内置模板告别灰杠骨架屏，按各自业务语义绘制高辨识度微缩彩色表格预览（「空白工作簿」清透行列头+中心新建徽章、「销售明细」深海蓝表头+金额条+状态胶囊、「家庭预算」翡翠绿表头+收支进度条+结余高亮行、「项目排期」靛蓝时间轴+三色阶梯甘特条）。
  - 「最近打开」收拢进圆角白底表格卡片，补齐 `文件名称 / 所在位置 / 修改时间` 表头栏、行间细分割线、翠绿微缩工作表文件徽标与底部拖拽打开提示栏；右侧快捷键升级为带底沿厚度的立体键帽。

**验收**：`cargo test -p app --no-default-features --features glow` 单测 **404 passed / 0 failed / 1 ignored**，`ui_regression` **20 passed / 0 failed**；实机截图 `work/uiaudit/r56/v2_account.png`、`v2_about.png`、`v2_home.png`、`v2_wb_1440.png`。
