# QA-05.3 视觉差异门槛与五态规范

冻结日期：2026-11-16（本机 release/glow，1440×900 逻辑尺寸，ppp 1.0 基准）
适用：QA-05.1/05.2/05.3 的截图比对。**禁止只报全图相似度**，一律按下面的区域拆分。

## 1. 区域划分（按窗口高度比例）

| 区域 | 高度区间 | 说明 |
|---|---|---|
| title | 0.000–0.055 | 标题栏 + 快速访问 + 文档标签 |
| ribbon | 0.055–0.170 | 功能区（页签、分组、控件） |
| formula | 0.170–0.215 | 名称框 + 编辑栏 |
| grid | 0.215–0.940 | 列标/行号/网格/选区 |
| tabs | 0.940–0.975 | 工作表标签 |
| status | 0.975–1.000 | 状态栏（求和、缩放、视图按钮） |

比对工具：`scripts/qa05_region_diff.py REF.png CUR.png`。尺寸不同时先把 CUR
按 LANCZOS 缩放到 REF 尺寸（高 DPI 截图降采样）。

## 2. 门槛（首次测量冻结）

指标：`mean` = 灰度平均绝对差（0–255）；`big%` = 差值 >32 的像素占比。

| 区域 | mean ≤ | big% ≤ | 首测实测（1.25 / 1.5） |
|---|---|---|---|
| title | 7.0 | 8.5 | 5.67/3.30 · 5.85/7.05 |
| ribbon | 7.0 | 5.5 | 5.65/4.61 · 4.59/4.28 |
| formula | 7.5 | 6.5 | 6.24/5.26 · 4.93/4.84 |
| grid | 6.0 | 3.5 | 4.53/2.87 · 4.94/2.89 |
| tabs | 2.5 | 1.0 | 1.85/0.60 · 1.21/0.64 |
| status | 16.0 | 12.0 | 13.70/10.10 · 12.45/8.99 |

门槛 = 两档实测最大值 + 约 20% 余量。**这些差值几乎全是文字抗锯齿**，
所以 formula/status 这类小字密集区门槛必然偏高；门槛一旦冻结，只能按此上限
判断退化，不能因为「看起来还行」放宽。

### 反例验证（证明门槛能抓结构差异，不是摆设）

| 合成反例 | 结果 |
|---|---|
| 功能区整条下移 4px | ribbon `mean 11.03 / big 10.16` → **FAIL**，其余区域 0.00 |
| 状态栏整条抹白 | status `mean 27.49 / big 18.44` → **FAIL**，其余 0.00 |

命令与原始输出见 `implementation-evidence/qa05-region-diff.txt`。

## 4. 五态定义与实测色值

| 状态 | 表现 | 实测来源 |
|---|---|---|
| 静止 | 无底色（透明），文字 TEXT | `big_sized` 无指针 |
| hover | 底色 HOVER 243,242,241 | 注入 `PointerMoved` 后取绘制形状 |
| pressed | 底色 PRESSED 237,235,233 | `PointerButton{pressed:true}` |
| selected | 填充 ACCENT 33,115,70（如勾选框） | `check_row(checked=true)` |
| disabled | 文字/图标 DISABLED 166,166,166，无底色 | `add_enabled_ui(false)` |
| focus | 1.5px ACCENT 内描边圈（新增） | `request_focus()` 后取描边形状 |

自动校验：`cargo test -p app five_interaction_states_are_visually_distinct`
断言 hover/pressed/selected 各自的填充色出现、静止态没有、disabled 文字变灰、
focus 有 ≥1px 的 ACCENT 描边，且五种颜色两两 RGB 曼哈顿距离 ≥6。

**本轮修的缺陷**：功能区大按钮/小按钮此前完全没有键盘焦点指示（只有对话框
`primary_button` 有）。已新增 `ui_kit::focus_ring`，在 `big_sized`、`color_button`、
字体样式切换按钮上画焦点圈。

## 5. 尺寸与缩放规则

- 控件物理尺寸必须随 ppp 精确缩放：`粘贴` 按钮 1.0/1.25/1.5/2.0 → 42×76 /
  52×95 / 63×114 / 84×152（误差 ≤1px）。
- 缩放切换后选区外框必须与格线严格对齐：B2:C3 选区在 1.0/1.25/1.5/2.0 下
  宽 134/167.5/201/268、高 54/67.5/81/108，恰为 ×1.25/×1.5/×2.0，**无 1px 漂移**。
- 窄窗口：最小 760×420 不得出现控件越界（功能区最右元素 ≤ 窗口右边界）。

## 6. 已知边界

- 色板只覆盖浅色主题；深色主题走 `v.dark_mode` 分支，未纳入本规范。
- `vision_analyze` 在本轮不可用（连续超时），因此没有人工视觉评审，
  所有结论都基于像素度量与 UIA 几何。
- 1.25/1.5 的差值来自「同逻辑尺寸、不同物理分辨率」的降采样对比；
  2.0 因本机屏幕 2560×1440 放不下 2880×1800 而未纳入区域比对。
