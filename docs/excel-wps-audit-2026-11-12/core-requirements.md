### C01 P0 错误值模型与增量重算一致性

**对标行为：** 本机 Excel 与 WPS 在修改 B1 前后均保留 #DIV/0!；全量与增量结果一致。

**现状与定位：** `formula/mod.rs:2178 to_fvalue` 把所有 `Value::Text` 当普通文本；`:2188 from_fvalue` 又把 `FValue::Error` 转成文本；`:928` 增量范围外的公式直接读取这种缓存。`model.rs` 的 `Value` 没有 Error 分支。动态确认上表 C01。

**修改要求：** 建立显式错误值类型，并贯穿 xlsx/xls 读写、剪贴板、网络传输、撤销、持久化；保留“用户输入的文本 `#DIV/0!`”与真正错误的区别。不得通过“所有 `#` 开头字符串都当错误”的补丁解决。增量重算的范围外缓存必须保留类型。低层 xlsx 的 `Data::Error` 不应转成 Debug 拼接的文本。

**验收：** C01 三阶段始终为 `#DIV/0!`；IFERROR 能捕获，SUM 不吞掉真正错误；普通文本 `'#DIV/0!` 仍是文本。覆盖七种传统错误、SPILL，跨表、外链缓存、保存重开、只改另一个依赖项。每轮增量结果与克隆后全量重算逐格比较类型与数值。先增加失败测试再实施模型迁移。
