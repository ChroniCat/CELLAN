# 端到端验收操作集

每条使用独立合成副本，记录程序版本、提交、操作入口、预期/实际、截图或文件差异、结论。结果只能为通过、失败、未执行、受环境阻断；未执行不得算通过。Excel与WPS有差异时记录两份结果并由产品明确选择，不猜测。

## 3 视觉、性能与可访问性

- **V01：** 760×420、1024×768、1440×900、1920×1080；100/125/150/200%DPI。常用命令可发现，窗口按钮/对话框底部按钮完整，禁止用UI整体缩放冒充工作表缩放。
- **V02：** 工作表50/100/200%；冻结、合并、图表、拖选、自动滚动和命中位置一致，标题/Ribbon物理尺寸不变。
- **V03：** 只用键盘完成打开、定位、编辑、格式、查找、保存；菜单Esc逐级关闭；模态Tab不进入背景网格；Narrator能读单元格坐标/内容/状态。
- **P01：** release构建固定后端；1万/10万/100万非空格、长公式链、远端稀疏格分别测打开到可编辑、滚动输入延迟、重算、保存、峰值内存。先建立基准，再冻结p95/内存不退化超过10%的门槛；数值正确性不能交换性能。
- **P02：** 长任务有进度和取消；取消不留下半导入数据/半保存文件；后台完成结果归属正确文档标签。
