# UI-07.1 / QA-04.2：cua-driver 真实 UI 复制粘贴（2026-11-18）

## 结论

在 `GetForegroundWindow()=0`、SendInput/WM_CHAR 不可用的同一会话里，
`computer_use`（cua-driver）仍能对 app.exe 做 **UIA 元素点击** 和 **网格坐标点击**：

- 点击网格 `A1`（native 80,284）后名称框从 A2 变为 A1；
- `Shift+Right` 后统计栏显示 B1 的 `10`（选区从 A1 扩展）；
- 点击 Ribbon 的复制元素（#28，tooltip「复制」）后状态栏：
  `已复制 (0, 1, 0, 1)（1 行 × 1 列）`
- 点击 D1（native 302,284）后点击 Ribbon「粘贴」（#25）：
  - D1 公式栏显示 `=C1*2`，值 `0`，统计 `平均值:0 计数:1`
  - 源 B1 为 `=A1*2`、值 10；复制后相对引用按目标列平移，
    这是真实 app 剪贴板通路（不是 SC_KEYSEQ 注入）。

截图：

- `b1-copied.png`：复制后 B1 选中，状态栏显示「已复制 (0,1,0,1)」
- `d1-formula-paste.png`：D1 选中，公式栏 `=C1*2`，值 0

## 限制（不冒充）

- 这里的复制/粘贴是 **UIA Invoke Ribbon 按钮**，不是物理右键菜单或物理 Ctrl+V。
- `computer_use` 的 `key("ctrl+c")` 在该 app 上经 PostMessage 落成字面字符 `c`/`v`
  （观察：B1 进入编辑并出现 `cv`，Esc 后恢复 `=A1*2`），
  `delivery_mode="foreground"` 返回 `foreground_unavailable`（HWND 0x0）。
- 因此「物理右键复制 / 物理 Ctrl+V」仍不标通过；本轮新增的是
  **真实 UI 点击复制/粘贴+相对引用平移**。

## 操作序列（可复现）

1. `computer_use capture app="app.exe" mode="som"`；
2. 点击网格 native `(80,284)` 选 A1；`Shift+Right` 扩到 B1；
3. UIA Invoke `#28`（复制）→ 状态栏「已复制 (0, 1, 0, 1)」；
4. 点击 native `(302,284)` 选 D1；
5. UIA Invoke `#25`（粘贴）→ D1 公式 `=C1*2`、值 0。
