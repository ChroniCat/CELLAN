C01.2 XLS/XLSX 缓存类型、外链缓存与粘贴
========================================
日期：2026-11-13 UTC+08   对标：core-requirements.md C01（切片 C01.2）

一、这一轮查出的四个真问题
--------------------------
1. **XLS 写读两端字节序相反**（`xls_write.rs` / `xls_read.rs`）
   BOOLERR 记录的布局是 `(bBoolErr, fError)`。写端原来 push 的是 `(1, code)`，
   读端按 `body[7] == 0` 判布尔、`body[6]` 当值 —— 于是错误格写出去后
   读回来 `body[7] = 0x07 ≠ 0`、`body[6] = 1` 不是合法错误码，整格**丢失**（读成 Empty）。
   修：写端 `push(code); push(1)`；读端 `fError != 0` 时按 `body[6]` 映射错误码。

2. **XLS 读端只认 fError = 0**：`if body[7] == 0 { Bool }` 没有 else，
   所有错误格被静默丢弃。补 else 分支 + `err_kind_from_biff`。

3. **FORMULA 缓存值的特殊值布局**：旧代码只看 `body[12..14] == 0xFF`
   且把 `body[6]` 当类型字节，与写端（放在 `body[6..8]`）不一致。
   现在两种布局都认：`body[6..8]==0xFFFF → (type=body[8], val=body[9])`，
   否则看 `body[12..14]==0xFFFF → (type=body[6], val=body[8])`；
   type 0=字符串（值在后续 STRING 记录）/1=布尔/2=错误/3=空。

4. **外链缓存与粘贴把错误吞成空/0**
   - `xlinks` 读缓存：`"e" => Value::Empty` → 改成 `ErrKind::from_text(&text)`；
   - `xlinks` 刷新：`Data::Error(_) => Value::Empty` → 按 calamine 类型映射；
   - 粘贴：`Kind::Error => 0`（当成数字）→ 改成 `4`，粘贴路径 `cell.kind == 4`
     用 `from_text` 还原成 `Value::Error`（公式缓存值那条分支也加）。

二、用例（`crates/core/tests/error_persistence.rs` 4 项 + app 1 项）
--------------------------------------------------------------------
| 用例 | 断言 |
|---|---|
| `xls_roundtrip_keeps_error_and_bool_types` | 写 .xls 再读：Div0/Na/Ref 是 `Error(..)`、布尔是 `Bool`、`Text("#DIV/0!")` 仍是文本 |
| `xlsx_roundtrip_keeps_error_type_after_a_second_save` | 存→读→改一格→再存→读，错误类型不退化 |
| `xlsx_writes_errors_as_type_e_not_text` | 包内 XML 恰有 3 个 `t="e"`，文本 `#DIV/0!` 不算 |
| `external_link_cache_keeps_error_type` | 外链缓存 `(0,0,0)` 读回 `Error(Div0)`，数字读回 Number |
| `pasting_an_excel_error_cell_keeps_it_an_error_value`（app） | XMLSS `ss:Type="Error"` → `convert_block` kind=4；粘贴后 Div0/Na 是错误值、`ss:Type="String"` 的 `#DIV/0!` 仍是文本 |

三、变异验证（真实输出）
------------------------

        test xls_roundtrip_keeps_error_and_bool_types ... FAILED
          left: Empty   right: Error(Div0)

    [2] 把粘贴映射改回 Kind::Error => 0

    的断言后才抓住，这也说明只测下游不测映射会留下假通过。
