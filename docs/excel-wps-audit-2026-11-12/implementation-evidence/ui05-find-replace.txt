# UI-05 查找替换：稀疏搜索、范围/顺序、整格与公式模式、一次撤销

日期：2026-11-14 01:0x CST
审计基线：find_next 按每行 16384 格遍历并硬截 400 万步（A1→A300 不可达）；
只查当前表显示值；replace_current 用 contains 预检；replace_all 只查 Text 且无事务。

## 现状

- `sheetcore::search`：基于稀疏模型建候选，命中带 (sheet, row, col)；
  `next_hit` 按选定顺序找严格下一处，到边界回卷并返回 wrapped 标记。
- 查找范围：当前工作表 / 整个工作簿 / 当前选区（含 Ctrl 多选快照 `session_rects`，
  与命中光标分离，连续“下一个”不会退化成单格）。
- 顺序：按行 / 按列。
- 模式：值（显示文本，含格式化数字）/ 公式文本；“整格匹配”按整串比较；
  值模式命中公式结果默认不替换，必须显式勾选“替换公式结果”。
- 替换全部：分帧扫描（可取消）→ 先算差异 → 按表分组做保护/锁 preflight →
  一次多表事务提交 → 统一重算/广播；命中数与实改数分别统计并可在状态栏解释。
