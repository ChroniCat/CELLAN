# C10 结构化引用特殊字符转义：验证补充

日期：2026-11-13；C10.1 已验收，本轮只补转义边界，不重开 C10.1。

## 实现

- `table.rs`：`escape_ident` / `unescape_ident` 对 `[ ] # ' @` 前置单引号；
  `replace_col_token`、spec 循环、`rename_specs` 按转义感知处理；
  `split_quoted_structured` 只把真正的 `'Sheet'!` 限定符当引号，
  不把列名转义误判成字符串边界。
- `rename_table_column` 同步表头文本；`New#` 输出 `New'#`（Excel 形式）。

cargo test -p sheetcore --offline --test structured_references

新增覆盖：

- `=SUM(Specials['#OfItems])` -> 10
- `=SUM(Specials[At'@Name])` -> 20
- `=SUM(Specials[Bracket']Close])` -> 30
- `=SUM(Specials[A''Quote])` -> 40
- `=SUM(Specials[A'[Bracket])` -> 50
- `#OfItems` 改名为 `New#` 后公式 `=SUM(Specials[New'#])`，表头同步，
  重算仍 10。

## 真实 Excel 16.0 探测（输入 -> COM 返回 -> 值）

```text
=SUM(Specials['#OfItems])        -> =SUM(Specials['#OfItems])        10
=SUM(Specials['At'@Name])        -> =SUM(Specials[At'@Name])         20
=SUM(Specials['Bracket']Close])  -> =SUM(Specials[Bracket']Close])   30
=SUM(Specials['A''Quote])        -> =SUM(Specials[A''Quote])         40
=SUM(Specials['A'[Bracket])      -> =SUM(Specials[A'[Bracket])       50
```

Excel 会规范化转义写法；保存/加载验收看输入、返回公式、值三列。

## 边界

- 只覆盖列名转义，不等同于 C10 全部结构化语法的独立复核。
- C10 父项仍未验收。
