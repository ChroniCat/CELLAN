# UI-17.3 分列：列类型/覆盖确认/完整撤销

日期：2026-11-14

## 复核发现并修复

`run_split` 的权限门禁与撤销事务只覆盖用户选中的原始矩形（例如 A1），
但分列会向右写出 `width` 列（A1:C1），导致：

- 被覆盖的 B1/C1 不在权限检查内；
- 撤销只还原 A1，B1/C1 的覆盖与新写入内容留在表里 —— **撤销不完整**。

修复（`crates/app/src/main.rs::run_split`）：

```rust
let dry = text_to_columns_ex(..., true);          // 先只预览
let c2w = (c2 + dry.width.max(1) - 1).min(16_383); // 扩展右边界
let keys = undo::rect_keys(r1, c1, r2, c2w);
if !self.write_preflight(&keys, "分列") { return; } // 权限看整块
...
let txn = self.txn_begin(&keys);                   // 撤销捕获整块
```

顺序改为“先 dry-run 得到宽度 → 再按扩展区域做权限门禁”，
不会出现先通过原始区域检查、随后写到锁定格的情况。
