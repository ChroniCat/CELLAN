# UI-22 真正的命令搜索

日期：2026-11-14

- 新增 `palette.rs`：把 `customUI.xml` 里所有可见控件（按钮/切换/拆分/菜单及其子项/
  下拉/库/组合框/滑块/编辑框）摊平为命令表，动作名与功能区共用，执行走同一个
  `ribbon_action`，不维护第二份命令清单。
- 搜索：空格分词、全部命中；匹配命令名、action、分组、页签，英文不区分大小写。
- 入口：Ctrl+Q；标题栏搜索框聚焦或输入时打开并把文字带进搜索。
  标题栏搜索框不再误当工作表查找（工作表查找仍是 Ctrl+F 的查找栏）。
- 结果面板显示命令名 + 页签 › 分组，最多 40 条，Enter 执行第一条，Esc 关闭。
- GUI 实测（`SC_KEYSEQ=ctrl+q`）：弹窗「命令搜索」显示 **203 条结果**，
  前几条为 打开/保存/另存为/打印预览/导出 PDF/历史版本/撤销/重做/新建标签…，
  路径显示「文件 › 文件」「文件 › 打印」等；截图 `ui22/palette.png`。
- 单测 `palette::tests::filters_by_label_path_and_action`：中文、页签+分组、英文 action、
  空查询、无结果五种情况。
- app `--bin app` **273 passed**。
- 未做：真实键盘逐字输入/方向键选择（RDP 注入不可用）；结果排序按 ribbon 顺序，未做使用频率学习。
