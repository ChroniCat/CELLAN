UI-08.3 边框粗细/颜色无损提交（2026-11-13 15:01 CST）

问题
- 旧确定逻辑只要任一 border bool 变化，就把四边统一写成 style=1；
  原有左侧粗框 style=2、右侧双线 style=4 会被降成细灰线。
- 这与 UI-08.2 的“只提交改动字段”冲突：数字格式/字体已按字段 diff，
  边框却仍整组覆盖。

实现
- 按 side 比较 fmt_state.border 与 fmt_orig.border，得到 side_changed[4]。
- 只对 side_changed[i] 为真的边写 style=1/0；未改动边的 style 和 color 原样保留。
- “外框”仅在四边同时从未开启变为开启时清内部边；只切换单边时不再触发内部
  边清理，避免破坏其它边。
- 新增回归：原样式左粗红 style2、右双蓝 style4、上下无框；只打开下框，
  确定后左/右的 style 和 color 逐项不变，下边为 style1，上边仍为 0。

验证
- edit_regression_tests::format_dialog_preserves_border_thickness_and_color_when_other_side_changes
  -> 1 passed。
- 全量：cargo test -p app --offline --bin app -> 217 passed / 0 failed / 0 ignored，
  APP_EXIT=0。
