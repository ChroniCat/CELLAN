UI-11.6 跨工作表引用：编辑中点另一张表页 → Sheet2!A1
=====================================================
日期：2026-11-16
代码：`crates/app/src/main.rs`
测试：`crates/app/src/edit_regression_tests.rs`（4 条 ui116 用例）

一、原来是什么行为
------------------
编辑公式时点工作表标签 = `commit_edit()` 直接提交并切表，引用丢了。
台账里留的那条就是它：「跨工作表点选建 Sheet2!A1 未实现（点另一张表页会先结束当前编辑）」。

二、改法
--------
1. 编辑会话记住所属表与目标格：`edit_sheet: Option<usize>`、`edit_sel: Option<(u32, u32)>`
   （`begin_edit_at` 里落值）；
2. 新增 `switch_sheet_for_ref(idx)`：公式编辑中只切视图、不提交；非公式编辑仍走原来的 `switch_sheet_view`；
3. 新增 `return_to_edit_origin()`：`commit_edit` / `cancel_edit` 开头先切回编辑所属表与原格，
   所以回车写的是原表原格，不是当前看的这张表；
4. 引用标签统一走 `qualify_ref()`：视图不在编辑表上时加 `Sheet表名!` 前缀，
   工作表名含空格/标点/数字开头时按 Excel 规则加单引号（`'我的 表'!B3`），内部单引号翻倍；
5. 表格点选收敛成一个入口 `insert_pick_reference(r, c)`，行号/列标（`C:C`、`5:5`）也走同一套加前缀。

三、无界面探针（真跑 GUI，不是单测）
------------------------------------
```
SC_UI116=1 SC_SHOT=... SC_SHOT_FRAMES=8 SC_SHOT_EXIT=1 app.exe multi-A.xlsx

[ui116] pass4  sheet=0 editing=true  buf="=1+"
[ui116] pass6  sheet=1 label=Sheet2!B3 buf="=1+Sheet2!B3"     ← 视图已切到第二张表
[ui116] pass12 ok=true sheet=0 sel=(0, 0) formula==1+Sheet2!B3 value=43
[ui116] done
[shot] 已保存 work/probe/ui116/shot.png (1440×900)
```
第 8 帧截图逐项核对（vision_analyze 分区读图）：
- 名称框：`A1`
- 公式输入框：`=1+Sheet2!B3`
- 底部标签：`Data`（灰）/ `Sheet2`（白底 + 绿色下划线 = 激活）
- 状态栏：`单元格模式 输入` / `已插入`

也就是说：**人在看 Sheet2，光标还在 Data!A1 的编辑会话里，引用已经带上了 Sheet2! 前缀**。
回车后值 43（Sheet2!B3 = 42，+1），公式落在 Data!A1。

六、边界
--------
- 跨表拖动扩区域（按住拖到 Sheet2!B3:C4）没做：拖动状态建立在当前表的坐标轴上，
  跨表要另存一份「远端锚点」；这一轮只做点选单格与整行整列。
- 三维引用（Sheet1:Sheet3!A1）不涉及。
