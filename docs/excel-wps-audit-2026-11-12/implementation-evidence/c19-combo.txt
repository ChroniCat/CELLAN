# C19.2 组合图：逐系列类型与次坐标轴（解析/绘制/保存保真）

日期：2026-11-14
夹具：`crates/core/tests/fixtures/c19/combo.xlsx`（Excel 16.0 生成，`scripts/c19_combo_fixture.ps1`）

```text
销售!A1:C5 = 月份/销量/增长率（增长率 0% 格式）
图表：簇状柱形，系列 1 柱（主轴），系列 2 折线 + AxisGroup=2（次坐标轴）
chart1.xml: <barChart> axId 1933580879/1933583759
            <lineChart> axId 1933598639/1933597199
```

## 1. 解析

`Series` 增加 `kind: Option<ChartKind>`、`secondary: bool`；`charts.rs` 按 chart 容器
（barChart/lineChart/area/pie/doughnut/scatter）记录起始系列号与 `<axId>` 对，
容器结束时归位；不同容器用不同 axId 对 → 该容器系列标次轴（第一个容器视为主轴）。
`barDir=bar` 只影响所在容器的 Column→Bar。

```text
combo_chart_keeps_per_series_kind_and_secondary_axis ... ok
kind=Combo  series[0].kind=Column secondary=false
series[1].kind=Line  secondary=true  vals=[0.12,0.25,-0.4,1.22]
```

## 2. 绘制（屏幕/预览/PDF 共用）

`print::draw_chart` 改为按系列取图型与量级：主轴系列用主轴最大值，次轴系列用次轴最大值；
柱/条按柱系列序号并排，折线/散点连线，面积闭合填充；有次轴时右侧画一条轴线。

```text
print_ops_draw_both_series_types_with_secondary_scale ... ok   (rects≥4 且有折线)
```

## 3. 保存

umya 保存会重写 `xl/charts/chart1.xml`，并丢掉它没建模的属性（本夹具 `<c:numFmt>` 4→2）。
新增 `fixups::restore_chart_parts(path, base, keep)`：基准里有、保存后仍在、且用户没改过的
图表部件按基准逐字节还原；`Workbook.chart_edits` 记录应用里改过类型的部件，插删行列导致
`ref_fixes` 非空的部件也排除在外。

```text
editing_a_cell_does_not_rewrite_the_combo_chart ... ok        (部件字节不变，重开类型/次轴仍在)
an_explicit_chart_type_change_is_not_reverted_by_save ... ok  (改成柱后保存仍无 lineChart)
```

Excel 16.0 / WPS 打开我方保存的文件：

```text
EXCEL SERIES=2 TYPE1=51 TYPE2=4 AXIS2=2
WPS   SERIES=2 TYPE2=4 AXIS2=2
```

即：两根系列、系列 2 仍是折线、仍在次坐标轴，原图未降级。

## 4. 逐系列编辑入口（本轮补）

图表编辑对话框的系列行加了「图型」下拉（跟随图表/柱/条/折线/面积）与「次轴」勾选；
`chart_write` 不再按“前 N 柱、其余线”切分，而是按（图型, 主轴/次轴）分组，
每组一个 chart 容器、次轴组用 axId 3/4 并写右侧 valAx；折线系列写
`<c:marker><c:symbol val="none"/></c:marker>`，Excel 才认成 xlLine(4) 而不是带标记的 65。

```text
writer_groups_series_by_kind_and_axis_pair ... ok
EXCEL WRITER SERIES=2 TYPE2=4 AXIS2=2
WPS   WRITER TYPE2=4 AXIS2=2
```
