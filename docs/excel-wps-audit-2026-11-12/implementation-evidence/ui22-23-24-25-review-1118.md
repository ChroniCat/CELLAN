## 分项

### UI-22 / UI-22.1 命令搜索

- `palette::filter` 覆盖命令名/action/页签/分组、空格分词、空查询和无结果；`command_palette`
  用同一 `ribbon_action` 执行，结果最多 40 条。
- 使用频率学习与持久化在 `ui16-ui22-1117.md` 里已记录。
- 2026-11-18 后续：`ui22-physical-1118.md` 已用真实键盘补齐逐字输入、方向键选择、
  Enter 执行第二条命令、Esc 回网格；UI-22.1 的键盘 not_done 已清空。

### UI-23 / UI-23.1 KeyTips 与右键菜单键盘

- KeyTips 两级序列、Home 控件唯一性、跨页签到边框/筛选/冻结均有用例。
- **未做**：真实物理键盘 Alt / Shift+F10 / 方向键 / Enter；真实鼠标在右下角单元格右键未做。
  `SC_KEYSEQ` 与 `CtxAct` 回归只证明事件分发，不证明物理按键。

### UI-24 / UI-24.2 对话框语义与屏幕阅读器

- accesskit 树已把功能区组名、二级菜单项、强制打开的 split 菜单项暴露出来。
- `a11y_split_button_arrows_open_their_galleries` 仍是 ignored：无头注入不展开 split/gallery
  箭头热区，需有头/真人环境。
- **未做**：真实 NVDA/讲述人朗读与真实鼠标点箭头展开。

### UI-25 / UI-25.1 状态栏统计

- 统计定义、多矩形、筛选/手动隐藏/大纲隐藏、隐藏列不参与、上下文菜单隐藏标记均有用例。
- **未做**：真实鼠标 Ctrl 多选、右键“隐藏行”；筛选与手动隐藏重叠同一行时按集合并集去重
  （结果口径一致，但无法像 Excel 那样归因到某一种隐藏原因）。
