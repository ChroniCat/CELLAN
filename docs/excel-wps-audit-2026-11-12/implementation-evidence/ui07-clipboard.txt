UI-07 普通粘贴各入口共用真实系统剪贴板（证据）
日期：2026-11-14
提交：537dbe5（父基线 73c3b64）
环境：Windows 11 / Excel 16.0 (Excel.Application) / WPS 12.0 (KET.Application) / app(glow) debug
夹具：work/qa07/source.xlsx（A1 日期 2026-01-02、B1 1234.50、B1:C1 合并、A2 单元格内两行、B2 =B1*2、A1 粗体+黄底）；work/qa07/blank.xlsx

一、三入口共用最新系统剪贴板（App 复制 1 → 模拟 Excel 复制 2）
回归：edit_regression_tests::ribbon_context_and_shortcut_paste_share_the_latest_system_text
命令：cargo test -p app --offline -j 2 --bin app ribbon_context_and_shortcut_paste -- --test-threads=1
结果：1 passed; 0 failed
覆盖：先 app.clip_copy 建立内部 “旧值” clip，再 set_test_clipboard("7\t8\n9\t10\n")；
  Ribbon  app.ribbon_action("Paste")
  右键    app.ctx_menu_run(CtxAct::Paste, 0)
  快捷键  app.clip_paste(false, None)（Ctrl+V 走同一入口）
  三个入口在 A1/A4/A7 都得到 7，右下列都得到 10；内部旧值没有盖住外部新值。

二、App → Excel（HTML + TSV 写剪贴板）
命令：SC_SEL="0,0" SC_SEL2="1,2" SC_KEYSEQ="ctrl+c" SC_CLIP_LOG=1 ... app.exe work/qa07/source.xlsx
剪贴板 HTML 实测（节选）：<td ... x:num="46024">2026-01-02</td>、colspan="2"、mso-number-format:'#,##0.00'、
  x:fmla="=B1*2"、<br style="mso-data-placement:same-cell;">、background:#FFFF00、font-weight:bold。
Excel 16.0 打开 work/qa07/blank.xlsx，Range("A1").Paste()，另存 work/qa07/excel-out2.xlsx，COM 回读：
  USED=$A$1:$C$2
  A1=#######（列宽不足）；A1V=46024；A1FMT=yyyy-mm-dd
  B1=1,234.50
  A2=第一行<LF>第二行
  B2=2469（公式丢失，HTML 的 x:fmla 不被 Excel 普通粘贴采用）
  MERGE=True（B1:C1）；BOLD=True；FILL=65535（黄色）
结论：日期类型/数字格式/中文/合并/单元格内换行/粗体/填充保留；公式向外丢失（见第六节）。

三、App → WPS
同一份剪贴板，在 WPS 表格 (KET.Application) 打开 work/qa07/blank.xlsx，A1 Paste，另存 work/qa07/wps-out2.xlsx，Excel COM 回读：
  USED=$A$1:$C$2
  A1=#######；A1V=46024；A1FMT=yyyy-mm-dd
  B1=1,234.50
  A2=第一行<LF>第二行
  B2=2469（公式丢失）
  MERGE=True；BOLD=True；FILL=65535
结论：与 Excel 一致；WPS 也不采用 HTML x:fmla。

四、Excel → App（Ribbon 粘贴）
步骤：Excel COM 打开 source.xlsx，A1:C2 Copy，保持 Excel 进程 45 秒；app 打开 blank 副本：
  SC_CMD="20:Paste;60:FileSave" ... app.exe work/qa07/ribbon.xlsx
日志：  [cmd] frame 20 -> Paste
        [paste] office 块 2x3
        [save] 已保存 work/qa07/ribbon.xlsx
Excel COM 回读 ribbon.xlsx：
  A1=######；B1=1,234.50；A2=第一行<LF>第二行；B2==B1*2
  MERGE=True；BOLD=True；FILL=65535
结论：XML Spreadsheet 路径保留公式、数值格式、合并、粗体、填充、单元格内换行、中文。

五、Excel → App（Ctrl+V）
步骤：同一 Excel 剪贴板；SC_KEYSEQ="ctrl+v" ... app.exe work/qa07/key.xlsx
日志：  [keyseq] frame 6 -> ctrl+v
        [paste] office 块 2x3
Excel COM 回读 key.xlsx：
  A1=######；A2=第一行<LF>第二行；B2==B1*2；MERGE=True；FILL=65535
结论：与 Ribbon 一致；Ctrl+V 不再被内部旧 clip 截获。

六、WPS → App（Ribbon 粘贴）
步骤：WPS KET.Application 打开 source.xlsx，A1:C2 Copy；app:
  SC_CMD="20:Paste;60:FileSave" ... app.exe work/qa07/wps-ribbon4.xlsx
日志：  [paste] office 块 2x3
Excel COM 回读 wps-ribbon4.xlsx：
  A1=######；A1V=46024；FMT=yyyy-mm-dd
  B1=1,234.50；A2=第一行<LF>第二行；B2==B1*2
  MERGE=True；BOLD=True；FILL=65535
结论：WPS 的 HTML class 样式（et2/et3）、数字实体（&#31532;…）、x:num、mso-number-format 已解析；
  日期以序列号 46024 + yyyy-mm-dd 存回；公式来自 WPS 的 XML Spreadsheet。

八、格式损失清单（双向 2×3）
保留：
  App→Excel/WPS：日期显示与 yyyy-mm-dd 格式、金额 #,##0.00、中文、合并、单元格内换行、粗体、填充。
  Excel/WPS→App：上述格式 + 公式（XML Spreadsheet）、数值/日期类型、合并。
丢失：
  App→Excel/WPS：公式（HTML 的 x:fmla 不被普通粘贴采用，B2 落成缓存值 2469）。
  App→Excel/WPS：A1 列宽未随内容扩展，显示 #######；值/格式正确（值 46024，格式 yyyy-mm-dd）。
  仅 HTML 的 App→App（例如进程重启后无内部 clip）：公式会退化为值；内部 clip 路径保留公式。
