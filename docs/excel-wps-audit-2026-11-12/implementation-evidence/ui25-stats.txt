# UI-25 状态栏统计：多选、筛选、大选区与入口

日期：2026-11-14

## 本次关闭的四个缺口

1. **多选区**：统计不再只看 `sel_rect()`，改为遍历 `sel_rects()`（主选区 + Ctrl 追加块）。
   A1=1、A4=3 非连续选择：计数 2、数值计数 2、求和 4、平均 2、最小 1、最大 3；
   截图 `implementation-evidence/ui25/multi-select.png`。
2. **大选区不再消失**：删除 `cells <= 200_000` 硬门槛。选区面积 > 50,000 时建立
   `StatsJob`，先按 Store 实际存在的格子收集（百万行稀疏表不逐坐标扫），再每帧最多
   累加 200,000 格；至少跨一帧，状态栏显示「计算中… 已处理 N 格」。
3. **过滤隐藏策略**：统计跳过筛选 `Filter::hidden_rows()`、隐藏行（行高 0）、隐藏列
   （列宽 0）。单测用真实 `Filter` 把 B 行筛掉，结果只统计 A 行。
4. **入口常驻**：`统计 ▾` 不再依赖“统计文本非空”。六项全关（mask=0）时入口仍在，
   右键可重新勾选；菜单新增「复制统计结果」，文本标签右键同样可用。
   截图 `implementation-evidence/ui25/mask0.png`。

## 实测
- 范围 A1:A4（A2 空、A3 文本）：平均值 2 / 计数 3 / 数值计数 2 / 求和 4 / 最小 1 / 最大 3，
  与 Excel 口径一致；截图 `implementation-evidence/ui25/range-a1a4.png`。
- 多选 A1+A4：计数 2、求和 4；截图 `multi-select.png`。
- mask=0：只显示「统计 ▾」，无统计文本；截图 `mask0.png`。
- 回归：
  - `status_stats_cover_multi_rect_filter_and_sparse_edges`
  - `status_stats_follow_active_filter_hidden_rows`
  - app `--bin app` **287 passed**
- 探针：`SC_STAT_MASK`、`SC_EXTRA_SEL`。
