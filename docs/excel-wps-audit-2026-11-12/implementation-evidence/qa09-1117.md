# QA-09 验收证据：PDF / 打印真实产物（2026-11-17）

对标方式：同一份夹具，本程序用**导出对话框同一条函数**（`SC_EXPORT_PDF` →
`export_pdf_to`）出 PDF；Excel 16.0 / WPS 12.0 用各自 `ExportAsFixedFormat` 出 PDF；
再机械比对页数、文字、词框、字体、边距与位图。

机器结果：`implementation-evidence/qa09/report.json`
（脚本 `scripts/qa09_verify.py`，可重跑：
`uv run --with pymupdf --with openpyxl python scripts/qa09_verify.py`）。

## 机械判据与结果（全部夹具）

| 判据 | 结果 |
|---|---|
| 词框出页面（文字被切断） | 0 / 全部页面 |
| 词框重叠 >50% 且 >25pt²（文字重叠） | 0 / 全部页面 |
| 正文越出页边距 | 无（`body_inside_margins=true`） |
| 只嵌 TrueType 子集，无系统字体依赖 | `Embedded` + `EmbeddedBold`，`Type0` |
| 导出后原文件 sha256 变化 | 无（6/6 `source_sha_unchanged=true`） |
| 页码 | `print`/`hidden` 每页 `第 N 页`，`1/2`、`2/2` 正确 |

### 行完整性（print.xlsx，2 页）

- `行10`…`行60` 共 **51 个行号 token，每个恰好出现 1 次**，`missing=[]`、`duplicates={}`；
- 两页都重复打印标题「2026 年第一季度销售汇总」；
- 与 WPS 的文字多重集只差换行断点（`…折行` / `，不能各算一套。` 被断成两个词），语义一致；
- 与 Excel 文字多重集差 2 个词，是 Excel 把重复标题画在页面末尾的顺序差异。

### 对象（objects.xlsx）

- 图片 1 张 + 矢量图 11 段 + 文本框文字「打印文本框」；
- 图片 bbox 与 WPS 差 0.6pt（见 `c16-pic-anchor-1117.md`）；
- Excel 文字多重集与本程序**完全相等**（`words_missing_in_pdf=0`、`extra=0`）；
- WPS 少 11 个图表文字词，是 WPS 把图表栅格化后文字不可提取，不是缺内容。

### 隐藏/筛选（hidden.xlsx，新增）

- `hidden_absent=true`：隐藏列 B、手动隐藏行 5、筛选隐藏行 7 的内容全部没进 PDF；
- `visible_present=true`：可见行/列/合并标题/页脚齐全；
- Excel 同夹具导出同样不含隐藏内容；唯一词差是 Excel 把合并标题截成「隐藏行列打印样」。

### 适应纸张（fit_width.xlsx，新增）

- 18 列 × 31 行，`fitToWidth=1`：本程序与 Excel **都压到 1 页 A4**；
- 文字流 `text_equal=true`（2385 字，逐字符相同）；
- 最右列标题 x=515.0pt，页面宽 595.3pt、右边距 0.7in → 不越界。

## PDF 字体子集裁剪（原 not_done「4.4MB 未裁剪」）

新模块 `crates/core/src/font_subset.rs`：按文档实际用到的字形重写 `glyf/loca`，
**字形号不变**（PDF 是 Identity-H，CID=GID，所以 ToUnicode/Widths 都不用改），
复合字形把部件一起带上；`GSUB/GPOS/GDEF` 等排版表不嵌。

| 产物 | 裁剪前 | 裁剪后 | 降幅 | 150dpi 位图 |
|---|---:|---:|---:|---|
| `print.xlsx`（2 页，中文混排） | 5,724,165 B | **669,491 B** | -88.3% | 与裁剪前逐像素相同（diff=0，ink 21614） |
| `pdf_bold_demo`（常规+真粗体） | 5,694,019 B | **630,739 B** | -88.9% | ink 8157 与裁剪前完全一致 |

测试：`crates/core/src/font_subset.rs` 2 条（gid 不变、复合字形轮廓不丢）、
`crates/core/tests/c16_pdf_bold.rs::pdf_embeds_only_glyphs_actually_used`。
