# UI-16.1 / UI-22.1 实现证据（2026-11-17）

## UI-16.1 每表视图包含视图模式

旧实现 `SheetViewState` 只存 `sel/sel_end/extra_sel/scroll/zoom`，切表时
「普通 / 页面布局 / 分页预览」沿用当前全局值，A 表停在分页预览、切到 B 表
仍然是分页预览；Excel 是每张表各自记住。

修正：

- `SheetViewState` 增 `view_mode: u8`（0 普通 / 1 页面布局 / 2 分页预览）；
- `remember_sheet_view` 写入、`load_sheet_view` 恢复；
- 新表无记录时默认 0（普通），和 Excel 新表一致。

测试：`sheet_view_state_is_restored_by_stable_identity` 扩展为
「第一张表设 2 → 切新表为 0 → 切回第一张仍是 2」，并保留改名/重排/identity
不串表的原断言。

```
cargo test -p app --bin app -- sheet_view_state_is_restored_by_stable_identity --test-threads=1
→ 1 passed; 378 filtered out
```

右键标签菜单、拖动排序仍未做真实鼠标取证（本机无交互桌面），该项保持待验收。

## UI-22.1 命令使用频率学习

命令搜索原来只做子串过滤，结果顺序 = 功能区遍历顺序，常用的「冻结窗格」
可能排在很后面。

实现 `crates/app/src/cmdusage.rs`：

- `%LOCALAPPDATA%\SheetsNative\cmdusage.txt`，一行 `action<TAB>次数`；
- `touch(action)` 在 `ribbon_action` 入口调用——功能区点按和命令搜索执行
  共用同一份计数，不另建第二套「最近使用」；
- 命令面板每帧 `rank(&mut hits, &load())`：次数降序、同频按 action 名；
- 文件坏行/读失败只当空表，不影响命令执行；写失败也不影响命令本身。

测试（LOCALAPPDATA 隔离，TestEnv）：

```
cargo test -p app --bin app -- cmdusage --test-threads=1
→ 2 passed
  - counts_survive_reload_and_rank_desc（Bold×2 > CenterAlign×1 > 未用过）
  - touch_is_isolated_by_localappdata（不同测试目录互不串）
```

真实键盘逐字输入/方向键选择仍未做（无交互桌面），该项保持待验收。
