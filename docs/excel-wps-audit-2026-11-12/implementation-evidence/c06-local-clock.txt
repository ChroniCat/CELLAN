C06 本地时间与 1900 序列 60 兼容
================================

状态：已验收（2026-11-13 09:30）
范围：crates/core/src/formula/functions.rs、formula/mod.rs、style.rs 的日期格式化路径。

一、实现
--------
1. `date_to_serial_in(DateSystem::D1900, 1900, 2, 29)` 显式返回序列 60；
   `serial_to_date_in` 对 60 返回 `(1900, 2, 29)`，不再与 61 一起落到 03-01。
   此时 DAY(60)=29、MONTH(60)=2、YEAR(60)=1900、TEXT(60,"yyyy-mm-dd")="1900-02-29"。
   1904 体系不接受公历不存在的 1900-02-29，保持 None。
2. `now_serial` 由 UTC 改为“注入/系统时钟 + 本地 UTC 偏移”；新增
   `with_clock_at(unix_secs, offset_seconds, f)` 注入接口。默认仍读系统时钟和
   本机时区，注入只作用于闭包，不改变全局状态。
3. `NOW/TODAY` 在 `Calc` 生命周期内使用同一个本地序列号快照；`recalc_all_force`
   与 `recalc_sheet` 在多遍 spill 稳定化之间也保持同一快照，结束后恢复外层值。
   NOW 纳秒级小数按秒精度换算，TODAY 取快照的 floor。
4. `style.rs` 的日期格式化继续走 `serial_to_date_in`，所以单元格格式与 TEXT
   在序列 60 上一致。

三、本机 Office 对拍
--------------------
Excel 16.0（PowerShell COM，空白新建工作簿，未修改用户文件）：
  A1 = TEXT(60,"yyyy-mm-dd") -> 1900-02-29
  A2 = DAY(60) -> 29
  A3 = MONTH(60) -> 2
  A4 = YEAR(60) -> 1900
  A5 = TEXT(59,"yyyy-mm-dd") -> 1900-02-28
  A6 = TEXT(61,"yyyy-mm-dd") -> 1900-03-01
  A7 = DATE(1900,2,29) -> 60
  A8 = TODAY() -> 46339（本机 2026-11-13，+08:00）
  A9 = NOW() -> 46339.3937146991（约 09:26）
  ExcelVersion=16.0；本机 LocalNow=2026-11-13 09:26:57 +08:00。

WPS 12.0（Ket.Application，同样的空白工作簿）：
  A1 1900-02-29、A2 29、A3 2、A4 1900、A5 1900-02-28、A6 1900-03-01、
  A7 60、A8 46339、A9 46339.3938194444；WPSVersion=12.0；
  LocalNow=2026-11-13 09:27:06 +08:00。

结论：本应用与 Excel 16.0/WPS 12.0 在序列 59/60/61、DAY/MONTH/YEAR/TEXT/
DATE 上逐项一致；NOW/TODAY 使用本地 +08:00 钟面。未执行项：没有把本机系统时区
实际切换到其他时区（通过 `with_clock_at` 注入验证时区和午夜边界，未改系统设置）。
