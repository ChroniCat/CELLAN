UI-24.3 网格坐标值与选区语义（UIA 实测）
================================================================================
日期：2026-11-16

一、要解决的问题
---------------
自绘网格在读屏软件眼里只有「一块画布」。行号、列标、选区范围都不存在，
Narrator 只会念到一个孤零零的单元格名，用户无法知道「选了几行几列」、
「当前在第几列」，也没法按列标导航。

二、做了什么
------------
1. 网格汇总节点（Role=Grid）：
   `工作表 Sheet1，选区 B2:C4，3 行 2 列，活动单元格 B2`
2. 列标：每个**可见**列发布一个 `Role=ColumnHeader`，
   名字 `列 A`；落在选区内时 `列 B，已选中`。带真实屏幕坐标（accesskit bounds）。
3. 行号：每个**可见**行发布 `Role=RowHeader`，`第 2 行` / `第 2 行，已选中`。
4. 活动单元格节点（上一轮已做）继续给 `B2，4，已选中` / `B2，金额，公式 =A1*2，已选中`。
5. 只对可见行列建节点（屏内约 20 列 + 30 行），不给 1,048,576 行建树。

三、失败 → 通过（外部 UIA 客户端实测）
-------------------------------------
本轮之前（`qa07-values-10000.xlsx`，选区 A1）：
```
COUNT=115
DataItem  A1，0，已选中        ← 网格在树里只有这一条
```
本轮之后（同文件，默认选区 A1）：
```
COUNT=168
DataGrid  工作表 Sheet1，选区 A1:A1，1 行 1 列，活动单元格 A1
DataItem  A1，0，已选中
DataItem  列 A / 列 B / 列 C …（可见列各一条）
DataItem  第 1 行 / 第 2 行 / 第 3 行 …（可见行各一条，共 31 条）
```
多格选区（`SC_SEL=1,1` + `SC_SEL2=3,2` → B2:C4）：
```
DataGrid  工作表 Sheet1，选区 B2:C4，3 行 2 列，活动单元格 B2
列 B，已选中    bounds=497,593,67,19
列 C，已选中    bounds=564,593,67,19
列 D            bounds=631,593,67,19     ← 选区外，不标已选中
第 2 行，已选中  bounds=401,630,29,18
第 4 行，已选中  bounds=401,666,29,18
第 5 行          bounds=401,684,29,18     ← 选区外
```
坐标来自 accesskit bounds（已乘 pixels_per_point），列宽 67px、行高 18px，
与界面实际列宽/行高一致；列 B→C→D 的 x 依次 497/564/631 递增 67，说明定位真实。

四、哪些没做（口径）
------------------
- **`SelectionItemPattern` 没暴露**：试过 `GetCurrentPattern(SelectionItemPattern)`，
  UIA 报 `no-pattern`。accesskit 0.17（egui 0.31 依赖的版本）把 selected 作为状态位，
  UIA 适配层没映射成 SelectionItem 模式。所以选中态**写进名字**（`，已选中`），
  读屏能读到，但辅助工具无法通过模式查询 IsSelected。要修得换 accesskit 版本或自己接管
  UIA provider，属于后续独立任务。
- 选区变化时不会主动发 UIA 通知（`RaiseNotificationEvent` / LiveRegion），
  读屏要重新读屏才看到新选区。
- 没有给冻结区/合并单元格/隐藏行列做特殊语义。
- 只覆盖可见范围，滚动到新区域要下一帧才有节点（本来就是每帧重建）。
