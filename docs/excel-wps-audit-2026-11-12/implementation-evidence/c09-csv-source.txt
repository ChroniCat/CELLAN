C09：首次导入与刷新共用同一解析 / 编码 / 列类型模型
====================================================
状态：已验收（2026-11-13 04:49 复核，按最终代码与测试证据）。
阅读顺序：先看「当前结论」「最终实现」「最终验证」；第 1–5 节是首版历史记录，
其中「未执行 / 待补」里的预览对话框、刷新撤销、默认 encoding 登记等已在第 6 节关闭，
原文保留仅作审计轨迹（标注【历史 RED】）。

当前结论
--------
- 首次导入与刷新共用 decode + records_strict_q + import_csv_opts 单一管线。
- 显式指定编码失败不回退；自动探测才 BOM→UTF-8→GB18030。
- 文本列、引号、分隔符、表头、实际编码随源持久化；保存重开后刷新复用。
- 解析失败不写旧区域；短行刷新与首次导入逐格一致。
- 刷新是一步可撤销操作，撤销同时恢复源 rows/cols。

最终实现
--------
1. crates/core/src/csv.rs
   - Encoding {Utf8,Utf16Le,Utf16Be,Gb18030} + id/from_id。
   - decode(bytes, Some(enc))：解码失败返回 ("", enc, true)，绝不回退 GB18030；
     decode(bytes, None)：BOM → 严格 UTF-8 → GB18030。
   - records_strict_q / parse_strict_q：未闭合引号、闭引号后多余字符返回 Err；
     保留引号内换行、CRLF、转义引号、尾空列、空行语义。
2. crates/core/src/external.rs
   - CsvOpts { encoding: Option<Encoding>, text_cols: Vec<u32>, quote: char }（手写 Default，quote='"'）。
   - import_csv_opts 返回 (rows, cols, used_enc)；先完整解析再一次性写入。
   - Source.csv_opts 持久化名尾部追加 |enc|cols|q<码点>，旧文件按自动处理。
   - mutate/refresh 传入同一配置与旧尺寸；缩小时只清自己上次写过的块；短行缺失列清空。
3. crates/app/src/main.rs
   - 选文件后进 CsvDlg（编码/引号/表头/按列文本 + 真实 records_strict_q 预览），
     确认走 import_csv_choice → import_csv_opts；首次导入把 used_enc 写回 CsvOpts。
   - refresh_import：刷新前整表快照 + 源尺寸前后值入一步 undo；失败快照还原。
   - undo/redo 的 refresh_sizes 分支恢复 wb.sources 的 rows/cols。

【历史 RED】第 1–5 节（首版，2026-11-12）
-----------------------------------------
原始缺陷：首次导入走 csv::parse_auto，刷新走 text.lines()+split_line；
引号内换行被拆行（实测 (3,2) vs 期望 (2,2)）；刷新只 read_to_string（UTF-8）；
所有列自动转数字（00123→123、18 位账号变浮点）；先写后判错。

首版修改：
1. csv.rs 增加 Encoding / decode / records（BOM → 显式编码 → 严格 UTF-8 → GB18030）。
2. external.rs 增加 CsvOpts（编码 + 文本列），Source 文本尾部 |enc|cols；
   import_csv_with 先构建完整网格再一次写入；刷新复用同一路径。
3. app import_csv_from 不再 from_utf8_lossy + parse_auto，失败快照还原。

首版测试：csv_import 6 passed；应用层 1 passed。
RED/变异 M1：records 换回 text.lines() → 用例失败 left (3,2) right (2,2)，已还原。

六、round2（04:08/04:29 复核后）
1) 严格解析：csv::parse_strict_q / records_strict_q 对未闭合引号、闭引号后多余字符返回 Err；import_csv_opts 在写入前解析，失败时旧区域一个格都不动（bad_quote_on_refresh_keeps_previous_cells_untouched）。
2) 指定编码不回退：decode(Some(Utf8)) 遇到非 UTF-8 返回 had_errors，不落 GB18030；自动探测（None）才回退。指定编码失败时导入/刷新报错且保留原值。
3) 首次导入记录实际编码：import_csv_opts 返回 (rows, cols, used_enc)，应用写入 CsvOpts.encoding=Some(used_enc)。
4) 短行一致：刷新时新矩形内缺失列在旧区域内清空，A,B\nC,D → A\nB,C 后 B1 为空，与首次导入逐格一致（short_row_refresh_matches_first_import_for_the_same_rectangle）。
5) 刷新 undo：refresh_import 以整表快照 + 源尺寸前后值入栈一步；do_undo 恢复值、范围与 wb.sources 的 rows/cols（app 用例 refresh_is_one_undo_step...）。
6) 导入前选择：open_csv_dialog + csv_dlg_ui 提供编码/引号/表头/按列文本勾选与真实预览；确认走 import_csv_choice，CsvOpts 持久化 encoding/text_cols/quote（名称文本第 10 段 q<码点>）；保存重开后 refresh 复用（app 用例 csv_import_choices_persist_and_refresh_reuses_them）；csv_import_dialog_renders_with_real_preview_before_any_write 渲染一帧并断言取消前不写任何格。
7) 结果：csv_import 10 passed / 0 failed；app 159 passed / 0 failed；core 全量 592 passed / 41 ignored（round37，CORE_EXIT=0）；GUI 12 passed / 8 ignored。

边界（未写成通过）
------------------
- Excel/WPS 编码向导三方对拍未执行。
- 导入对话框的确认/取消是状态级 + 渲染帧 + 处理函数验证，没有系统键鼠点击。
