## 实际变更（2026-11-13 15:56 CST）

- `CellStyle` 新增 `locked`（默认 true）与 `hidden`（默认 false），并纳入样式哈希；
  旧文件没有 `<protection>` 时按 Excel 默认锁定、不隐藏载入。
- `xlsx` 读取 `calamine::Protection`；写入仅在非默认值时生成
  `<protection locked="…" hidden="…"/>`，避免给普通样式堆无意义节点。
- 格式对话框页签扩展为：数字 / 对齐 / 字体 / 边框 / 填充 / 保护。
  - 填充页：背景颜色开关、颜色选择器、混合状态提示。
  - 保护页：锁定、隐藏公式复选框，混合状态提示，以及“工作表保护后生效”说明。
- `FmtState` / `FmtMixed` / `FmtTouched` 增加 `locked`、`hidden`；混合字段被用户明确
  操作后按 `FmtTouched` 提交，未碰字段保留原值。

## 16:21 监督复核后的已有文件逆向写回修复（930ff80）

缺陷：`save_plain_base` 对 fill 只在 `Some` 时设置，对 protection 只在
`!locked || hidden` 时设置；已有文件里的旧 `<fill>` / `<protection>` 会跟着基准样式
留在 styles.xml，格式对话框把 fill 取消、locked/hidden 改回 `true/false` 后，内存正确但
save→reload 仍是旧填充/旧保护。`apply_protection` 只处理工作表 XML，补不了 styles。

修复：对 style_edits 中每个目标格，`st.fill == None` 时 `s.remove_fill()`；
`st.locked && !st.hidden` 时 `s.remove_protection()`。其它未改样式字段不动。

回归（不是只新建文件或内存断言）：
`edit_regression_tests::format_dialog_clears_fill_and_protection_on_existing_file`
1. 先生成带 `fill=rgb(200,10,10), locked=false, hidden=true` 的 xlsx；
2. `xlsx::load` 进入已有文件，确认对话框读到旧三值；
3. 真实调用 `open_format_dialog` → 清 fill、locked=true、hidden=false →
   `apply_format_dialog`；
4. `xlsx::save_atomic` → `xlsx::load`，断言 `fill=None`、`locked=true`、`hidden=false`。

结果：
- 修复前：`TEST_EXIT=101`，断言 `重开后旧填充必须清掉`，实际 `Some([200,10,10])`；
- 修复后：`1 passed / 0 failed`；
- 全量 app：`230 passed / 0 failed / 0 ignored`，`APP_EXIT=0`；
- 全量 core：75 bins / `679 passed / 0 failed / 41 ignored`，`CORE_EXIT=0`。
