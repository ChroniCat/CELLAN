C11 兼容检测：双引号字符串与转义边界
=====================================

问题（用户 13:38 监督指出）
---------------------------
`unsupported_reference_combo` 的字节扫描只找 `[`、`]`、`:`、`!`，
没有跳过 Excel 双引号字符串。于是：

  ="[1]First:Third!A1"
  =IF(TRUE,1/0,"[1]First:Third!A1")

都会被误判为“外部工作簿三维引用”。如果单元格缓存是 7，eval 的兼容
分支会在 parse 前直接返回 7，分别把普通文本和真实 #DIV/0! 保住。

修复
----
`crates/core/src/formula/mod.rs::unsupported_reference_combo` 改为：

1. 遇到 `"` 进入字符串扫描；
2. 连续两个 `""` 视为字符串内的转义引号，成对跳过；
3. 直到单独 `"` 才回到公式扫描；
4. 只有字符串外的 `[` ... `]` 且限定符内 `!` 前含 `:` 才命中。

没有扩大未知函数或普通 parse 失败的兼容缓存范围；普通外部单表
`[1]First!A1`、普通三维 `First:Third!A1`、未知函数仍不命中。

真实 recalc 负例
----------------
测试：`crates/core/tests/c11_compat.rs::external_three_d_text_inside_strings_is_not_cache_preserved`

  A1: 缓存 7，公式 ="[1]First:Third!A1"
      recalc -> Text("[1]First:Third!A1")   （不是 7）

  A2: 缓存 7，公式 =IF(TRUE,1/0,"[1]First:Third!A1")
      recalc -> Error(Div0)                  （不是 7）

检测器边界测试同时断言：

  unsupported_reference_combo("=\"[1]First:Third!A1\"") == None
  unsupported_reference_combo("=IF(TRUE,1/0,\"[1]First:Third!A1\")") == None
  unsupported_reference_combo("=\"a\"\"[1]First:Third!A1\"\"b\"") == None
