UI-07 公式向外粘贴修复证据（2026-11-18）

修复：
  crates/app/src/office_clipboard.rs::build_xmlss
  公式从 A1 改为 R1C1：sheetcore::clipboard_xmlss::a1_to_r1c1(f, r, c)
  XML Spreadsheet 的 ss:Formula 必须是 R1C1；A1 写法会被 Excel 忽略，只粘缓存值。

单测：
  cargo test -q -p app --bin app --offline -j 2 -- --test-threads=1 \
    xmlss_formula_uses_r1c1_for_excel_paste
  => 1 passed

App 自身生成剪贴板（不是手写 XML）：
  SC_SEL=0,0 SC_SEL2=0,1 SC_KEYSEQ=6:ctrl+c \
    SC_CLIP_DUMP=work/probe/clip_app.xmlss \
    ./target/debug/app.exe work/probe/clip_app.xlsx
  dump 中的公式：
    <Cell ss:StyleID="sc0" ss:Formula="=RC[-1]*2">

Excel COM 直接粘贴 app 留下的系统剪贴板（未用 ClipFmt 重新设置）：
  B2f=5 B2v=5 C2f==B2*2 C2v=10

WPS COM 粘贴同一份 App XML Spreadsheet：
  B2f=5 B2v=5 C2f==B2*2 C2v=10
  首轮 app 剪贴板同时带 HTML+UnicodeText 时，WPS 优先走文本，C2f=10（公式丢失）；
  修复为「含公式的选区只写 XML Spreadsheet，不写 HTML/UnicodeText」后，WPS 直接粘贴
  得到 C2f==B2*2；不含公式的选区仍写 HTML/文本，保住底色/合并/纯文本兜底。

带样式端到端（clip_style.xlsx：A1:B1 黄底+粗体+B1 公式，A2:B2 合并）：
  Excel：D1f=5 E1f==D1*2 D1fill=65535 D1bold=True D2merge=True D2=中文
  WPS  ：D1f=5 E1f==D1*2 D1fill=65535 D1bold=True D2merge=True D2=中文
  说明：公式选区走 XMLSS-only 时，填充/粗体/合并仍由 XMLSS 的 Style/Interior/MergeAcross 保留。

结论：
  App→Excel、App→WPS 的普通粘贴都能保留公式；HTML 的 x:fmla 仍然不承担公式，
  公式由 XML Spreadsheet 的 R1C1 通路承担；WPS 的格式优先级由“公式选区不写 HTML/文本”保证。
