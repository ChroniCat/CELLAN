一、已实现
1) 合并（main.rs::toggle_merge）
- 先 write_preflight（他人锁定/保护整批拒绝）。
- 选区除锚点外有非空内容时，第一次只提示“只保留左上角「…」，其余 N 格内容会被删除；再点一次合并确认”，
  模型不变；第二次点击必须同时满足：同一 wb_epoch、同一 doc_gen、同一工作表、同一矩形、
  锚点内容与待删格内容快照完全一致才执行；换表/换文档/改内容都会重新提示。
  Esc、切换标签页、切换工作表标签、打开/新建文档都会清掉待确认与格式对话框挂起。
- 执行时删除非锚点内容（锚点值与格式保留），merge_range 拆相交旧合并；
  一个 undo Action 同时记录 MergeEdit(added/removed 差异) + 被删格 delta。
- 撤销/重做只按差异增删合并，不整表覆盖 merges；动作之后新增的无关合并保留。
  结构先完整规划再落盘：任一要恢复/新增的矩形与现有合并相交，整组放弃，并同时放弃
  同一动作的 CellDelta（不删值、不广播），保证结构/内容原子一致。
- 撤销恢复被删的每格内容/样式；重做再次删除；保存重开保留 merges 与锚点。
- 协作：被删格 broadcast_op(Empty)，合并状态 broadcast_merge；do_undo/do_redo 按
  Applied.merge_changes 广播实际增删的合并矩形。
2) 格式对话框（FmtState / fmt_merge_pending）
- “合并单元格/取消合并”只写挂起标记，点“确定”才调用 commit_fmt_merge → toggle_merge；
  取消/关闭清挂起，模型完全不变。
3) 格式刷（FormatPainter）
- 记录源区域 rect + 样式号矩阵 + 取样式时的 wb_epoch/sheet；按行/列取模平铺到目标选区。
  换文档/换表后样式号不可跨簿解释，套用前校验失败即取消，不套错样式、不新增撤销。
  支持拖选范围、单击一次自动退出、双击 ribbon 进入连续模式、Esc 结束。
- 目标一次事务、一次撤销；样式经 broadcast_style 同步；目标上限 20 万格。

1) 结构冲突与内容原子化（core/undo.rs）
- 旧逻辑：apply_merge_diff 逐项跳过相交结构，但 redo 仍遍历全部 CellDelta，把 B1=乙 清空，删掉另一合并的锚点。
- 新逻辑：plan_merge_diff 先在 cloned merges 上完成全部 remove/add 校验，任一 remove 找不到或 add 与现有合并相交即返回 None；
  undo/redo 收到 None 时把 Action 放回原栈，Applied.merge_conflict=true，不写任何单元格、不置 dirty、不广播。
- 用例：overlapping_merge_redo_conflict_keeps_values_and_both_structures_intact（真实非锚点乙 + B1:C1 相交结构）。
2) Esc 状态互斥（app/main.rs::handle_keys）
- 旧逻辑：格式刷分支先清 painter 后 return，后面的 drop_merge_confirmation 永远不执行；
  合并警告 → 启用格式刷 → Esc → 再合并会复用旧确认。
- 新逻辑：把格式刷/合并确认合并在同一个 Esc 分支；一次 Esc 同时清 format_painter、painter_double、merge_pending、fmt_merge_pending。
  只有合并警告时仍保持“已取消未确认的合并”文案。
- 用例：merge_confirmation... 中追加真实 key_event(Escape) 顺序断言。
