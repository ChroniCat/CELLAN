## 本轮实现

| 原需求验收条目 | 现状 |
| --- | --- |
| 输入 `=SU` 有 SUM/SUMIF 等可键盘选择 | 已实现：候选 8 项上限，↑↓ 循环高亮，Tab/Enter 接受，Esc 不参与 |
| `=SUM(` 显示参数 | 已实现：最内层未闭合函数取签名（SUM/SUMIF/IF/VLOOKUP/XLOOKUP/… 19 个） |
| `A1 → $A$1 → A$1 → $A1 → A1` | 已实现：F4 只循环缓冲末尾的 A1 引用，函数名/数字不参与 |
| 文本中间 Alt+Enter 插入原光标处 | 已实现：改用多行 `TextEdit`（同一 `grid_edit` id）让 egui 按光标插入 |
| 编辑 `=A1` 时点 B2 变成引用 | **未实现** |
| 中文候选 Enter 只确认候选 | **未实测**（真实 IME 不可用，见 UI-01/QA-04 边界） |
| 彩色引用 / 函数向导 / 真实最近使用 | **未实现**（UI-11.3 余项、UI-11.4） |

焦点处理：格内编辑与公式栏各自持有 `TextEdit` 状态；接受候选后显式把光标搬到缓冲末尾，
否则后续输入会插进函数名中间（这是本轮实际踩到的坑，`apply_formula_pick` 后重设
`CCursorRange`）。

- `=SU` 候选含 SUM/SUMIF；选 SUM 后缓冲为 `=SUM(`，且 `formula_help("=SUM(")` 有签名；

- `=SUM(B2:C3)` F4 只动末尾引用 → `=SUM(B2:$C$3)`。
