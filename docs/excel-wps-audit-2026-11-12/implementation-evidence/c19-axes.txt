## 1. 轴数字格式（百分比轴）

`Chart.y_fmt` 读第一个 `valAx` 的 `<c:numFmt formatCode>`，刻度按 `style::format_value`
渲染；轴顶端取“整齐值”（1/2/2.5/5×10ⁿ），0.9 的进度图刻度为 0/25/50/75/100%。

```text
percentage_axis_format_is_read_from_val_ax ... ok
percent_ticks_are_drawn_with_the_axis_format ... ok

writer_keeps_axis_number_format ... ok
EXCEL FMT=0%   （我方改写后 Excel 回读仍是 0%）
```

## 2. 散点非等距 X

`Series.xv` 读 `xVal` 的 numCache；散点绘制按真实 X 映射，不再按序号等距。

```text
scatter_series_keep_non_uniform_x_values ... ok   xv=[1,2,10,50,100]
scatter_points_follow_x_scale_not_index ... ok    相邻间距最大/最小 > 2
```

## 3. 负数 / 空值 / 错误值

Excel 的 numCache 会**省掉空单元格**只留 `<c:pt idx>`：之前顺序 push 会让后面的值左移。
改为按 `pt/@idx` 放回原位，空与 `#N/A` 都是 NaN，绘制时跳过（柱不画、折线不连该点）。

```text
negative_blank_and_error_values_keep_their_slots ... ok  [5, -3, NaN, NaN]
```
