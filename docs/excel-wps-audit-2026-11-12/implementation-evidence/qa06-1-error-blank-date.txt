QA-06.1 错误 / 空值 / 日期矩阵（Excel 16.0 与 WPS 12.0 实算对拍）
=================================================================
日期：2026-11-16
夹具：`work/qa06/qa06.xlsx`（由 `scripts/qa06_fixture.py` 生成，输入同时写在 `cases.json`）
矩阵：`crates/core/tests/fixtures/qa06/matrix.tsv`
用例：`crates/core/tests/qa06_matrix.rs::qa06_1_error_blank_date_matrix_matches_excel`

输入（sheet "S"）
-----------------
```
A1 空      A2 "文本"   A3 5     A4 TRUE    A5 #N/A
A6 =""     A7 0        A8 1.5   A9 45351   A10 "5"
A11 #DIV/0!  A12 45000   B1..B5 = 1,2,3,4,5
```

生成与对拍链路
--------------
1. `python scripts/qa06_fixture.py work/qa06`
   造输入 + 50 条待算公式（写在 `cases.json`，不写进 xlsx）。
   之所以不把公式直接写进 xlsx：openpyxl 原样写 `IFNA`/`DAYS` 会缺 `_xlfn.` 前缀，
   Excel 会认成 `#NAME?`（第一版就踩到了，见下）。
2. `powershell -File scripts/qa06_excel_probe.ps1 F:/…/work/qa06`
   打开夹具，**用 COM 把 50 条公式逐条写进 C 列**（让 Excel 自己解析），`Calculate()`，
   读回 `Formula` / `Text` / `Value2`，Excel 与 WPS 各导一份 `excel.tsv` / `wps.tsv`。
   实测输出：`Excel 16.0：50 条；WPS=12.0`。
3. `python scripts/qa06_merge.py work/qa06`
   合并成 `matrix.tsv`（group / formula / Excel 显示值 / Excel Value2 / WPS 显示值）。
4. `cargo test -p sheetcore --offline -j 2 --test qa06_matrix -- --test-threads=2`
   → **1 passed / 0 failed**。

比较口径
--------
- 错误码、布尔：按显示值严格比对（`#N/A`、`#DIV/0!`、`#VALUE!`、`TRUE`、`FALSE`）；
- 数字：按 **Excel `Value2`** 比较，相对容差 1e-9、绝对值下限 1e-9。
  不能用 `Text`：Excel 的 `Text` 是单元格格式下的显示值——平均值显示成 `11339.38`（真值 11339.375），
  日期格显示成 `1/1/2025` 或 `########`，都会造成假差异；
- 文本与空：按显示值严格比对。

对拍结果
--------
50 条全部与本机 Excel 16.0 一致（错误传播 16 条、空值/空字符串 17 条、日期 17 条）。
Excel 与 WPS 12.0 语义全部一致，只有两处显示差异：

```
=EDATE(45351,1)   Excel='45380'   WPS='########'   ← WPS 列宽不够，不是语义差异
=EOMONTH(45351,0) Excel='45351'   WPS='########'
```

矩阵里值得留档的几条真值
------------------------
```
=ISBLANK(A1)         TRUE     ← 真空单元格
=ISBLANK(A6)         FALSE    ← ="" 的公式格不是空单元格
=COUNTA(A1:A10)      9        ← 含 ="" 的格
=COUNTBLANK(A1:A7)   2        ← 空 A1 + ="" 的 A6
=SUM(A1:A4,A6:A10)   45357.5
=A10+1               6        ← 文本数字 "5" 被算术强转
=A10&1               "51"     ← 连接仍是文本
=SUM(A4)             0        ← 区域里的 TRUE 不计入
=TRUE+1              2        ← 字面量 TRUE 计入
=DATE(1900,2,29)     60       ← 1900 系统虚构闰日
=YEAR(60)            1900
=DAY(60)             29
=DATE(2024,13,1)     45658    ← 月份越界自动进位到 2025-01-01
=DAYS(45382,45351)   31
=IFNA(A5,0)          0        ← 必须是 0；第一版写成 #NAME? 是夹具的锅
```

踩到的坑
--------
1. openpyxl 直接写 `IFNA` / `DAYS` 公式字符串，Excel 按未知名称算成 `#NAME?`。
   改为由 Excel COM 写公式后正常。
2. `[string]::Format('{0:R}', $v2)` 遇到 TRUE 抛 FormatException；已按 bool/字符串/数值分支处理。
3. 数字比对误用 `Text` 导致 AVERAGE（11339.38 vs 11339.375）与日期（`########`）假差异；
   改用 `Value2` 后归零。
4. `ws["A6"] = ""` 在 openpyxl 里等于删除该格（Excel 视为真空），
   改用 `=""` 公式才有真正的“空字符串格”，也才测到 `ISBLANK=FALSE` / `COUNTA` 计入。
