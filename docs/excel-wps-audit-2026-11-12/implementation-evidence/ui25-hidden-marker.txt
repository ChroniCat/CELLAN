# UI-25 状态栏统计：手动隐藏行/列标记统一（Excel UIA 实测口径）

日期：2026-11-14
代码：`crates/app/src/main.rs:1991` `stats_hidden_rows()`、`:2004` `collect_stats_values()`、
`:2030` `status_stats_rects()`、状态栏调用点 `:28565`。
测试：`crates/app/src/edit_regression_tests.rs:7323`、`:7364`。

## 缺口（本轮修的真实问题）

`view_axes()` 把手动隐藏行列按 0 像素显示，但状态栏统计读的是**模型原始轴**：

- 右键「隐藏行」只写 `sheet.hidden_rows_user`（`main.rs:22398`），不写行高 0；
- 右键「隐藏列」只写 `sheet.hidden_cols`（`main.rs:22420`），不写列宽 0；
- 统计的跳过集合原先只由调用点传「筛选隐藏行」，手动标记完全没进统计。

结果：手动隐藏一行后状态栏求和仍把它算进去，与 Excel 不一致。

## Excel 16.0 (Build 20326) 状态栏 UIA 实测

探针：`implementation-evidence/ui25-probe/ui25-excel-uia2.ps1`
（Excel COM 造数据 + `System.Windows.Automation` 读 StatusBar 的 Name 列表）

| 场景 | Excel 状态栏 |
| --- | --- |
| 基准 A1:A4 = 1,2,text"x",4 | 平均值 2.333333333 / 计数 4 / 求和 7 |
| 手动隐藏第 2 行（`Rows(2).Hidden=True`，回读 True）后选 A1:A4 | 平均值 2.5 / 计数 3 / 求和 5 |
| 手动隐藏 B 列（`Columns("B").Hidden=True`，回读 True）后选 A1:B1（1,100） | 平均值 50.5 / 计数 2 / 求和 101 |
| 分级组合折叠 7:8 行（`Rows(7).Hidden` 回读 True）后选 A6:A8（7,8） | 平均值 7 / 计数 1 / 求和 7 |

结论（原样采纳）：

1. **隐藏行不计**，无论来自手动隐藏、筛选还是分级/组合折叠；
2. **隐藏列仍计入** —— Excel 状态栏只按行隐藏生效（与 SUBTITLE/SUBTOTAL 的行语义一致），
   不能把「隐藏」一刀切成「行列都排除」；
3. 「计数」统计非空格（文本计入），「数值计数/求和/平均/最小/最大」只吃数字。

原始输出（探针 2，已滤掉缩放控件噪声）：

```
STATUS[baseline-text A1:A4 (1,2,text,4)] = 平均值 2.333333333 || 计数 4 || 求和 7
COLB_HIDDEN=True
STATUS[manual-hidden-colB A1:B1 (1,100)] = 平均值 50.5 || 计数 2 || 求和 101
ROW2_HIDDEN=True
STATUS[manual-hidden-row2 A1:A4 (1,text,4)] = 平均值 2.5 || 计数 3 || 求和 5
ROW7_HIDDEN_AFTER_OUTLINE=True
STATUS[outline-hidden-rows A6:A8 (7,8)] = 平均值 7 || 计数 1 || 求和 7
```

探针 1（`ui25-excel-uia.ps1`）另测了筛选：C2:C5（10,20,30,40）只留 30 时
`平均值 30 / 计数 1 / 求和 30`；关闭筛选后 `25 / 4 / 100`。

## 代码改法

- 新增 `stats_hidden_rows(sheet)`：`hidden_rows`（筛选+分级）∪ `hidden_rows_user`（手动）
  ∪ `filter.hidden_rows(sheet)`，作为**唯一**的统计行过滤来源；
- `collect_stats_values(sheet, rects)` 不再接收调用点传入的跳过集合，内部统一取上述集合；
  删除原先「列宽 ≤ 0 就跳过」的判断（Excel 隐藏列仍计入）；
- 状态栏两处调用（大选区分帧 / 普通路径）都改成同一个入口，避免两条路径口径漂移；
- 探针 `SC_STAT_DUMP=<path>` 把状态栏这一帧的选区、隐藏标记与最终统计文本落盘；
  `SC_HIDE_ROWS=2,3` / `SC_HIDE_COLS=2` 写与右键菜单相同的标记集合（1 基）。

## 应用本身实测（target/debug/app.exe，glow）

夹具 `work/probe/ui25/fixture.xlsx`：A1=1 A2=2 A3=x A4=4 B1=100。
每个场景独立进程，`SC_STAT_DUMP` 取最后一帧。

```
# 基准：SC_SEL=0,0 SC_SEL2=3,0
rects=[(0, 0, 3, 0)]  mask=11  hidden_rows_user=[]  hidden_rows=[]  hidden_cols=[]
stat=平均值: 2.3333    计数: 4    求和: 7

# SC_HIDE_ROWS=2（等价右键隐藏第 2 行）
rects=[(0, 0, 3, 0)]  hidden_rows_user=[1]  hidden_for_stats=[1]
stat=平均值: 2.5    计数: 3    求和: 5

# SC_HIDE_COLS=2，选 A1:B1
rects=[(0, 0, 0, 1)]  hidden_cols=[1]  hidden_for_stats=[]
stat=平均值: 50.5    计数: 2    求和: 101
```

三组与上表 Excel 数字逐项一致。
