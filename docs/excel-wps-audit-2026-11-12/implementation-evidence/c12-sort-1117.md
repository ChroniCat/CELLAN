# C12.2 / C12.3 排序口径与字段面板（2026-11-17）

## 1. 排序口径（本轮新增）

台账留的缺口是「如需与 Excel 新建一致的默认排序，需在面板加拼音排序选项」。
现在 `PivotLayout.sort: AxisSort { Pinyin, Source }`：

- **拼音**（默认）：Excel 新建数据透视表的行为（A/B/C 实验已定论）；
- **数据源顺序**：与 Excel 打开既有文件时 cache `rowItems` 的顺序一致。

面板「表格形式」旁边加「排序依据」下拉，两项各带 hover 说明。
`compute()` 的行/列路径排序都按该口径走，`pivot_parts2::build` 的 `rowItems`
由网格行序生成，所以部件里的顺序与界面显示一致。

## 2. 真机验证

夹具（源顺序）：张三、阿里、曹操（拼音序应为 阿里、曹操、张三）。

我方生成的两种文件交给 Excel 打开并**重存**，读回 `pivotTable1.xml`：

```text
pinyin: <rowItems count="4"><i><x v="1"/></i><i><x v="2"/></i><i><x/></i><i t="grand"><x/></i></rowItems>
source: <rowItems count="4"><i><x/></i><i><x v="1"/></i><i><x v="2"/></i><i t="grand"><x/></i></rowItems>
```

`<x/>` 是下标 0 的省略写法，所以：

- 拼音：1,2,0 → 阿里、曹操、张三
- 源序：0,1,2 → 张三、阿里、曹操

Excel 打开无修复提示、重存后顺序**原样保留**，说明两种 `rowItems` 都被认可。

`pivot2_edit` 面板里接线（此前已实现，本轮补了排序口径与它的说明）。
