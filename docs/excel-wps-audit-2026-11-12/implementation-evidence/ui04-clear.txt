# UI-04 清除操作：重算、撤销、广播与入口一致性

日期：2026-11-13 00:2x CST（会话跨零点）
审计基线 df48672 指出的问题：Delete 循环只对活动格更新依赖；`clear_values` 不重算/不广播；
`clear_selection` 不统一 dirty/doc_gen；txn_end 不提供隐式行为。

## 现状（当前 HEAD）

所有入口已收敛到一个命令 `clear_rects(ClearPart)`（main.rs:8267）：

```text
sel_rects() 收集所有非连续矩形 → rect_keys 展开 → sort+dedup 去重
→ write_preflight(&keys, 动作名)        // 保护 / 只读 / 协作租约一次判完，失败整批不执行
→ txn_begin(&keys) … 改值/清格式 … txn_end(动作名, txn)
→ dirty + doc_gen
→ 清除格式/全部：broadcast_style(默认样式)
→ 清除内容/全部：recalc_and_broadcast(sheet, r, c 列表)
```

入口映射：
- Delete / Backspace（handle_keys）→ `clear_values()` → `clear_rects(Contents)`
- 右键“清除内容”（CtxAct::ClearContents）→ 同上
- 功能区“清除内容” ClearValues / “全部清除” ClearContent → `clear_values()` / `clear_all()`
- `clear_selection` 保留为薄封装，行为与上面同一个函数

- `clear_formats_and_clear_all_are_distinct_and_undoable`

```text
SC_SEL=0,0 SC_SEL2=1,0 SC_KEYSEQ="60:delete"        SC_SHOT_FRAMES=100
SC_SEL=0,0 SC_SEL2=1,0 SC_KEYSEQ="60:delete,150:ctrl+z" SC_SHOT_FRAMES=190
```

- `ui04-clear-recalc.png`：选区 A1:A2，A1/A2 空，B1/B2 显示 0，状态栏“已清除内容”，标题带未保存星号。

  D1 仍是红色加粗（清除内容不动格式）。
