# QA-06.2 溢出冲突（#SPILL!）与清占位恢复

日期：2026-11-17　Excel 16.0 Build 20326（中文界面）

## 1. 补的是哪条 not_done

台账原文：「#SPILL! 冲突与溢出清理只在单测里，未进 Excel 对拍矩阵」。
本轮把它做成 **Excel 实算对拍**：同一张夹具里先放占位值制造冲突，读 Excel 的
`HasSpill` 与锚点文本；再清掉占位值重算，读回真实溢出块逐格比。

## 2. 夹具与探针

`scripts/qa06_array_fixture.py` 追加 `BLOCKED` 三条（占位值随夹具写入）：

| 锚点 | 公式 | 占位格 |
|---|---|---|
| E130 | `=SEQUENCE(3)` | E132 |
| E140 | `=SEQUENCE(2,2)` | E141 |
| E150 | `=TRANSPOSE(B1:B5)` | F150 |

`scripts/qa06_array_probe.ps1` 新增两段：
1. 写入这三条公式 → `Calculate()` → 导出 `spill_conflict.tsv`（`anchor<TAB>锚点文本<TAB>HasSpill`）；
2. `ClearContents()` 清占位 → `Calculate()` → 导出 `spill_cleared.tsv`（与 `blocks.tsv` 同格式）。

## 3. Excel 实算结果

```
spill_conflict.tsv
E130	#溢出!	False
E140	#溢出!	False
E150	#溢出!	False

spill_cleared.tsv
E130	=SEQUENCE(3)	3	1	1	2	3
E140	=SEQUENCE(2,2)	2	2	1	2	3	4
E150	=TRANSPOSE(B1:B5)	1	5	3	1	2	5	4
```

注意口径：中文版 Excel 的显示文本是 **`#溢出!`**，不是 `#SPILL!`；判冲突不能比字符串，
要比 `HasSpill=False` 或英文错误码。

## 4. 本引擎对拍

新增 `qa06_2_spill_conflict_and_recovery_match_excel`（`crates/core/tests/qa06_array.rs`）：

1. 建簿：B1:B5 / C1:C5 数据 + 三个锚点公式 + `E132/E141/F150` 写 `"X"` 占位；
2. `recalc_all` → 断言三个锚点都是 `Value::Error(ErrKind::Spill)`（对应 Excel 的 `HasSpill=False`）；
3. 清占位（写 `Value::Empty`）→ `recalc_all` → 12 格与 `spill_cleared.tsv` 逐格一致。

```
cargo test -p sheetcore --test qa06_array -- --test-threads=2 --nocapture
[qa06a-spill] 占位冲突 3 条一致；清占位后核对 12 格
[qa06a] 增量重算 12 格，1040 格与全量一致
test result: ok. 3 passed; 0 failed
```
