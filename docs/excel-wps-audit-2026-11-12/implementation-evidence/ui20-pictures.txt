# UI-20 图片对象：内存模型、统一保存、撤销

日期：2026-11-14 04:0x CST
审计基线：InsertPicture 直接 `pic_write::insert_picture` 改磁盘、要求先保存；
app 的 image 依赖只开 png/jpeg 却允许选 gif/bmp；图片没有选择/拖动/缩放/删除，也不进撤销。

## 实现

- `pic::Picture` 增加 `data: Option<Vec<u8>>`、`ext`、`name`；新插入的图先只进内存，
  部件名是内容哈希 `xl/media/sc<hash>.<ext>`（重复保存不增生媒体）。
- `pic_write::apply(path, wb)`：保存收尾按 `pictures_dirty` 重写该表 drawing ——
  去掉旧 `<xdr:pic>` 锚点、保留图表/文本框锚点、重建图片关系、补 <drawing r:id>、rels、内容类型。
- 选区/拖动/缩放/删除：点击图内选中（框 + 右下角手柄），拖动移动、手柄缩放（吸附到行列），
  Delete 删除；每次操作一条 `PictureEdit`，撤销/重做按前后快照恢复，撤销后标 dirty 等保存。
- 渲染：新图直接解码内存字节（`mem_texture`）；已存图按部件读。
- `image` 打开 gif/bmp 特性，选择器允许的 png/jpg/jpeg/gif/bmp 都能解码；解码失败直接提示。

## 回归

```text
cargo test -p sheetcore --offline -j 2 --test ui20_pictures        -> 3 passed
cargo test -p app --offline -j 2 --bin app -- --test-threads=2 picture -> 2 passed
sheetcore 全量 81 bins / 738 passed；app --bin app 259 passed；ui_regression 20 passed
```

- `picture_inserted_in_memory_only_is_not_written_until_save`：只改内存时文件字节完全不变、无媒体部件
- `saved_picture_has_anchor_and_media_and_survives_a_second_save`：锚点 2,3→7,6、媒体字节一致、
  内容类型登记 png、重开读回同一矩形、二次保存媒体不增生
- `moved_picture_rewrites_anchor_and_deleting_it_removes_anchor`：移动后落盘新锚点；删图后 drawing 无 pic
- `deleting_a_picture_is_one_undo_step_and_restores_its_anchor`、`moving_a_picture_is_undoable`

## 真实窗口 + Excel 对拍

| 项 | 结果 |
| --- | --- |
| 插图不保存关闭 | `ui20-insert-unsaved.png` 图在 B3 可见；sha256 前后都是 `43f7cbd4…d7ff`，文件一字未改 |
| 插图后 Ctrl+S | Excel COM：`shapes=1 name=Picture 1 type=13 tl=B3 br=D6` |
| 改矩形 6,2→10,6 后保存 | Excel COM：`moved tl=C7 br=G11`；drawing from col2/row6 |
| 改矩形后 Ctrl+Z 再保存 | drawing from col1/row2（回到 B3） |
| 选中按 Delete 再保存 | Excel COM：`del shapes=0` |
| 重开自家应用 | SC_DUMP `pic … at=(2,1,5,3)`，锚点读回一致 |
| gif / bmp | 各插一张，SC_DUMP 打印 `pic …gif` / `pic …bmp`（走的是成功分支，不是 pic-broken） |

## 边界

- 保存时重写的是工作表**当前**的 drawing；本应用给每张图表单独建 drawing 的历史行为不变，
  图片和图表同表时会同时出现在同一 drawing 里（锚点按各自类型保留）。
- 未做图片裁剪/旋转/边框，验收范围只到插入/移动/缩放/删除/撤销/保存锚点。
