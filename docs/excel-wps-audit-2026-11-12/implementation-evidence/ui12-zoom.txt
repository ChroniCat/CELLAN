# UI-12.1 分离 UI 与表格 zoom

日期：2026-11-14

- 之前缩放对话框、Ctrl+滚轮、状态栏 ±/滑杆、点击百分比都调用
  `ctx.set_zoom_factor(z)`，等于把功能区/对话框/菜单全部放大。现在全部删除该调用，
  UI 始终 100%，`self.zoom` 只作用于表格视图。
- `layout::Axis::scaled(z)`：默认行高/列宽与自定义尺寸一起按 zoom 复制，隐藏行列仍为 0，
  不回写模型；`view_axes()` 返回缩放后的轴，因此绘制、命中、选区、冻结线、拖拽边界
  全部来自同一套缩放几何。
- 网格字号乘 `self.zoom`（普通格、富文本 run、文本框），行/列自适应仍按 100% 度量，
  不会把当前缩放写进文件。
- 列宽/行高拖拽改为：拖动增量 / zoom 折回模型宽度，避免 200% 下拖 1px 变 2px。
- 验收探针 `SC_ZOOM=2.0`（新增）。
- 实测（`c10/table.xlsx`，1000×700，SC_DUMP）：
  - 表格 pane 始终 `rect=(0,255,1423,829)`，功能区高度不变；
  - 200% 时同一文本排版宽度 57.1→110.7、27.6→52.2，列 x 110→187、182→331，
    行中心 283→292（行高 18→36），表格确实整体放大；
  - 100%/200% 截图：`implementation-evidence/ui12/zoom-100.png`、`zoom-200.png`。
- 测试：`grid_zoom_scales_axes_and_hit_testing`（2×/0.5× 尺寸与 index_at 命中）、
  `scaled_axis_scales_default_and_custom_but_not_hidden`；app **280 passed**。
- 未做：缩放后保持左上角单元格（当前 scroll 像素值不变）、对象/图片是否随 zoom 缩放、
  冻结窗格滚动下的命中矩阵仍需 UI-12.2/12.3 验收。
