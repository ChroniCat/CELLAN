UI-30.1 命令可达性：宏入口接入 Ribbon、未命中命令留痕、宏只在隔离副本上跑
================================================================================
日期：2026-11-16

一、原来的三个问题
------------------
1. 宏的「查看 / 运行 / 导出」只在没人调用的旧 `toolbar_notes`（main.rs）里，
   功能区的「审阅」页签没有入口 —— 用户点不到。
2. 未命中的 Ribbon 命令只在 `SC_RIBBON_LOG` 环境变量存在时 eprintln，用户看不到，
   测试也不会失败。
3. 「运行宏」直接打开用户当前文件、`$wb.Save()` 写回原文件 —— 违反「宏只在隔离副本上验证」。

二、改动
--------
1. `crates/app/assets/ribbon/customUI.xml`：审阅页签新增「宏」组
   `MacroView`（查看宏，只读）/ `MacroRun`（运行宏…）/ `MacroExport`（导出宏部件…）。
2. `ribbon/actions.rs`：新增三条 dispatch 臂，都先判 `wb.has_vba`：
   没有宏就写明确状态（「当前工作簿没有 VBA 宏…」），不会静默。
3. 兜底分支：`self.unhandled_action = Some(action)` + 状态栏「这个命令还没有接入：X」，
   环境变量日志保留为附加；入口处重置，避免旧值挂着。
4. `run_macro_via_excel`：先把当前文件复制到 `%TEMP%\sc_macro_run_<pid>_<ms>.<ext>`，
   Excel 只在这个副本上 `Run` + `Save`；成功后状态栏给出副本路径并注明「原文件未改动」，
   不再把用户文件写回、也不把副本内容替换进当前工作簿。

三、验证（真实执行，不是静态推断）
----------------------------------
1. 单元/回归（cargo test -p app --bin app，333 passed）
   - `unknown_ribbon_action_is_reported_to_the_user`：未知命令 → `unhandled_action` 有值、
     状态栏含「还没有接入」；随后执行 `Undo` 会清空该标记。
   - `macro_buttons_are_reachable_and_explain_missing_vba`：无宏文件三个按钮都出明确提示。
   - `macro_run_button_opens_the_runner_when_vba_exists`：有宏文件点「运行宏…」打开输入框。
   - `review_tab_exposes_macro_group`：审阅页签的「宏」组里三个 action 都在。
   - `every_action_is_dispatched`：从 `ribbon_action` 的 match 臂里**精确抽取**命令名
     （不再用 `contains("\"X\"")` 子串判断），逐个校验 XML 动作要么有同名臂、
     要么在 `command::COMMANDS` 注册表里、要么属于 `fmt:/InsertFn:/zoom:/fitw:/fith:/scale:`
     家族；缺失即测试失败。
2. 真机 GUI（SC_SHOT 抓 framebuffer）
   - `SC_TAB=6 SC_RIBBON_ACTION="MacroView;MacroRun;MacroExport" SC_RIBBON_LOG=1`：
     ```
     [ribbon] 动作 MacroView → 状态「当前工作簿没有 VBA 宏，先打开一个 .xlsm 文件」 表格 0 个
     [ribbon] 动作 MacroRun → 状态「当前工作簿没有 VBA 宏，没有可运行的宏」 表格 0 个
     [ribbon] 动作 MacroExport → 状态「当前工作簿没有 VBA 宏部件可导出」 表格 0 个
     ```
   - 截图 `ui30-ribbon3.png`：审阅页签最右侧出现「宏」组，含「查看宏 / 运行宏… / 导出宏部件…」。
3. 全量：core 106 个测试二进制 0 failed（work/goal-logs/ui30-core.log）；
   app 333 passed（work/goal-logs/ui30-app.log）。

四、还没做（不许当成通过）
--------------------------

  + 宏三个按钮的真机点击。其余按钮的可观察结果仍靠既有分组测试。
- 旧菜单 `toolbar_notes/toolbar_view/toolbar_data/toolbar_page` 仍在源码里（已无调用点），
  按契约「渐进删除」，本轮先保证能力可达，未删除。
- 复用性检查：`set_freeze/export_pdf/open_compare` 仍只被旧菜单引用；Ribbon 侧走的是
  `FreezeTopRow/FreezeFirstColumn/FreezePanes`、`ExportPdf`、`ShowChanges` 等独立实现，
  删除旧菜单前要逐项确认等价。
