UI-24.2 右键菜单语义（MenuItem + 快捷键 + 子菜单提示 + 粘贴图标条）
================================================================================
日期：2026-11-16

一、之前
--------
单元格右键菜单是纯自绘（`ctx_menu_window`，CtxRow 列表 + 手工键盘导航），
UIA 树里一条都没有。读屏用户右键后什么也读不到。

二、改了什么
------------
1. 每个菜单行发 `Role=MenuItem`：
   - 名字 = 标签 +（`，Ctrl+X`）快捷键 +（`，有子菜单`）；
   - bounds 用真实行矩形（CTX_W × 26）。
2. 粘贴图标条（粘贴/公式/数值/格式/转置）每格发 `Button` + 名字。
3. 分隔线不发布（本来就不可点）。

三、外部 UIA 实测（`SC_CTX_MENU=600,600` 打开单元格右键菜单）
-------------------------------------------------------------

四、顺带查出来的真问题（**没修**）
--------------------------------
**功能区/右键菜单没有任何「禁用态」**：`Ctl.enabled` 全部来自 XML 的
`enabled="true"`，运行期没有一处把它改成 false（`grep "\.enabled = "` 只命中
对话框里一个局部变量）。也就是说剪贴板空着时「剪切/复制/粘贴」照样可点，
和 Excel 的灰化行为不一致——这是功能差异，不是可访问性差异。
因此 `a11y_name(..., enabled=false)` 这条路径**无法用真实按钮验证**，
本轮不写「已验禁用态」。

五、边界
--------
- 子菜单展开后的条目没有单独 dump（`SC_CTX_SUB` 可用，但本轮未跑）。
- 右键菜单没有 `Role=Menu` 容器节点，行直接挂在窗口下（不影响朗读，影响层级语义）。
- 禁用态见第四节。
