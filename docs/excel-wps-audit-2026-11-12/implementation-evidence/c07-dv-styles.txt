## 模型

`dv::DvStyle { Stop, Warning, Information }`，XML 值 stop/warning/information；
`DataValidation` 新增 `error_style`、`show_error`（showErrorMessage）、
`show_prompt`（showInputMessage）。

`DataValidation::verdict(valid)` 是唯一的处置判定：

| 情况 | 结果 |
| --- | --- |
| 通过 | `Accept` |
| 不通过且 `show_error=false` | `AcceptSilently`（Excel 不拦输入） |
| 不通过 + stop | `Reject`（留在编辑框，Excel 的“重试”） |
| 不通过 + warning | `AskWarning`（是/否/取消） |
| 不通过 + information | `InformThenAccept`（只有确定，确定后写入） |

`prompt_text()`：`show_prompt=false` 或标题/内容都空时返回 None；否则标题+换行+内容。

## 写盘属性

`patch::dv_xml` 现在显式写 `showErrorMessage="1|0"`、`showInputMessage="1|0"`，
非 stop 时写 `errorStyle="warning|information"`。不写这两个布尔属性时 OOXML 缺省是 0，
Excel 会关掉警告，所以必须显式。

兼容策略：文件里**缺少** showErrorMessage 属性时按 true 处理，保住本项目此前
“不合规就拦”的既定策略与旧版自身写出的文件；只有显式 `showErrorMessage="0"`
才按 Excel 语义静默放行。openpyxl 生成的夹具默认写 0，所以夹具里的规则在
本程序里同样是“不拦输入”，这与 Excel 打开该文件的行为一致。

## 交互

- 警告/信息框是模态 `egui::Window`：`dialog_modal` 期间网格不响应；
  Enter=默认按钮（是/确定），Esc=取消（信息框 Esc 等同确定）。
- 警告框“是”才真正写入，且只对这一次提交跳过验证；“否”回编辑框；“取消”不写。
- 停止样式不弹框，状态栏给出原因，编辑框保留（原有行为）。
- 配置坏了（名称/列表来源解析失败、阈值公式解析失败）即使 `showErrorMessage=0`
  也把“数据验证配置无效：…”写进状态栏。

## 状态栏消息区

查证发现 `self.status` 此前只被赋值、从未绘制，所有诊断对用户不可见。
本次在状态栏“单元格模式”右侧加了消息区（截断显示 + 悬停全文），C07 的
“配置失效时可见诊断”因此才成立。该区域属于状态栏显示，UI-25 的
统计项/可配置项仍未做，本节不代替 UI-25。

## 监督复核后的修复：信息级"取消/Esc"（2026-11-13 23:0x）

缺陷（属实）：`resolve_dv_alert` 写成 `a.info_only || choice == Primary`，
`dv_alert_window` 又把信息框的 Esc 映射成 Primary —— 信息级按 Esc 会写入，
还会平白留一条撤销记录。

修复：
- 提交条件只认 `Primary`；信息框按钮改为"确定/取消"，提示行"确定：接受这个值　取消：不写入"。
- Esc 三种样式一律 = 取消；取消路径不 set 单元格、不开事务，因此不产生撤销记录。
- 警告框"否"仍回编辑框（Excel 语义），"取消"丢弃。

新增回归（app bin，`dv_` 组共 17 条）：

```text
dv_information_escape_cancels_without_write_or_undo   Esc：单元格空、undo.depth() 不变、
                                                      状态栏"已取消"；随后合法输入只加 1 条撤销
dv_information_cancel_button_discards_entry           "取消"按钮走同一个 resolve_dv_alert：不写、不记撤销
dv_information_ok_button_writes_once                  "确定"写入且只有 1 条撤销
```

GUI 证据（重拍）：
- `c07-gui-information.png`：信息框显示"确定/取消"+ 提示行；D2 在确认前仍为空。
- `c07-gui-information-cancel.png`：按 Esc 之后模态框关闭、D2 为空，状态栏
  "已取消输入: 信息: 超出范围: 这个值不在建议范围内"；同一次运行按 Ctrl+S 后
  用 openpyxl 回读文件，D2 仍为空（取消没有落盘）。

本机是断开的 RDP 会话（`bring_to_front` 报 foreground hwnd 0x0），Esc 由 `SC_KEYSEQ`
注入真实应用的帧循环，经同一个 `dv_alert_window` 处理，不是人工键盘。
