UI-21 真正的手动计算与工作表计算 —— 状态：已验收（2026-11-13 08:45；代码修正提交 564b979）

一、实现

1) 核心调度（core/model + core/formula + core/xlsx + core/patch）
- Workbook 新增 calc_manual / calc_pending / calc_pending_sheets：
  calc_pending_sheets 记录哪些工作表还有未算编辑，计算单表时只移除目标表，
  不把全簿“待计算”提示误清掉。
- recalc_all / recalc_dirty 在 calc_manual 时统一短路，只调用 mark_pending
  标记受影响的表（按 seeds 和依赖闭包），返回 0；手输、Delete、排序、
  验证下拉、粘贴等入口都走这一道门，不再由 app 各入口各自判断。
- recalc_all_force 是 F9 / “开始计算” / 切回自动模式的强制入口，清空全簿
  pending；recalc_sheet 只把目标表公式放进 Calc.scope，跨表公式读取缓存，
  不会因为另一张表的 RAND/OFFSET 等易失函数而触发全簿重算。

2) 工作表级 spill 计算（UI-21 风险 1）
- recalc_sheet 不再直接 write_back 旧结果：先把目标表旧 spill 和静态数组
  ref 覆盖区登记并清空，避免已有 SEQUENCE 尾格挡住扩大后的新数组
  （误 #SPILL!）；随后按目标表多遍求值，让本表依赖 spill 尾格的公式在
  数组写入后追上。
- clear_spills_sheet 只操作目标表，别的表的 spill 与缓存一格不动。
- 缩小时旧尾格会从 spilled 集合移除并写空；再次扩大时旧尾格已不是障碍。
- 整个路径没有调用 recalc_all_force；目标表依赖用 scope 内多遍稳定计算。

3) calcPr 前缀兼容（UI-21 风险 3）
- set_calc_mode 不再用字面量 <calcPr / </workbook>：
  find_element 按 local_name 扫描开始标签，跳过注释/CDATA/PI，保留
  x:workbook、x:calcPr 等合法前缀；新插入的 calcPr 继承根元素前缀。
- 手动模式写 calcMode="manual"，并移除 fullCalcOnLoad；自动模式删除
  calcMode/manual 属性，保留 calcId 等其它属性。
- read_calc_manual 用 local_name 读取，支持带前缀 calcPr；新增 zip 级
  读取用例（read_prefixed_calc_pr_from_zip）。

4) BIFF .xls 边界（不另立切片豁免 UI-21）
- CALCMODE(0x000D) 由每个 sheet_stream 写在工作表 BOF 之后；旧实现写在
  Workbook 全局流，内部读写测试能通过，但 Excel/WPS 实际都忽略并退回
  自动模式。本项已由实机打开验证并修正。
- xls_read 在 Workbook 记录流中扫描 CALCMODE，xlsx::load 在 CFB/.xls
  分支回填 wb.calc_manual。
- round_trips_calc_mode_through_xls 增加位置断言：CALCMODE 必须位于第
  一张工作表 BOF 之后；测试防止退回全局流写法。该断言只锁 BOF 之后，
  不声称已逐表验证“紧邻”；实际写入按每张 sheet_stream 执行。
- .xls 的数组溢出/动态数组不属于当前 BIFF 写入模型，保留为明确边界。

5) App
- “计算选项：手动”同步 self.manual_calc 与 wb.calc_manual，并置 dirty
  （保存模式变更）；CalcAuto 同时清空 calc_pending_sheets 后走强制重算。
- F9 / CalculateNow 走后台 recalc_all_force；CalculateSheet 走
  recalc_sheet_async(self.sheet_idx)。
- recalc_async 不再在 Some(sheet) 分支无条件 calc_pending=false；
  单表计算只清目标表的 pending，另一张表仍有未算编辑时徽标继续显示。
- 手动模式编辑后状态栏显示“手动计算 · 待计算（F9 重算）”，点击徽标
  等同 F9；保存/另存写 wb.calc_manual；打开手动簿跳过打开时的自动
  全量重算。

二、Office 缓存模式定义

- Excel 的 workbook.xml calcPr/@calcMode="manual" 表示打开后不自动重算
  公式，单元格显示文件里上次保存的缓存 <v>，直到用户按 F9/Calculate
  或切换自动。
- 本项目加载时读取 calcPr；manual 簿保留缓存、不自动 recalc_all，
  因此显示与 Excel 手动模式一致；编辑后只把受影响表标 pending，
  不把公式结果静默改掉。
- 保存时继续写 calcMode="manual"；移除 fullCalcOnLoad，避免 Excel 打开
  时反过来强制全算。calcId 保留，calcChain 不作为模式判定依据。
- 自动模式移除 calcMode 属性（而不是写 auto），依靠 Excel 默认值，
  并保留其它 calcPr 属性。
