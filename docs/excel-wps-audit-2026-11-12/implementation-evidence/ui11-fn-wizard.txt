一、做了什么
------------
1) 插入函数向导（功能区「公式 → 插入函数」、fx 按钮 → InsertFunction）
   - 左侧：引擎真实实现的全部 475 个函数，可按名字/首字母搜索；前缀命中的排前面。
   - 右侧：函数名、中文说明、签名（formula_signature）、按签名解析出的参数输入框
     （`[x]` 标成「（可选）」），以及实时公式预览。
   - 参数名解析：`SUM(number1,[number2],…)` → number1 / number2（可选）；
     `NOW()` 这类无参函数不画参数框；签名不固定的函数提示「参数直接在编辑框里输入」。
   - 一个参数都不填 → `=SUM()`，并且光标停在括号里（5 = 括号中间），接着可以直接点区域。
   - 已经在编辑一段公式时点向导：只插函数体，不再叠一个等号（`=A1+` → `=A1+SUM(B1)`）。
   - Enter = 确定（Excel 行为），Esc = 取消（沿用 ui_kit 对话框的统一行为）。
   - 打开时搜索框自动聚焦；当前函数滚进列表视野；确定/取消右对齐。
2) 函数库「最近使用的函数」不再写死 XML 里的五项：
   - 新增 fnrecent 模块，存 `%LOCALAPPDATA%\SheetsNative\fnrecent.txt`，一行一个，新的在上，最多 10 条；
     还没有任何记录时用 XML 原来那五项兜底。
   - 公式提交时扫描真实函数调用（`NAME(`，允许空格，只认引擎已实现的名字）并按出现顺序记账。
   - 功能区「函数库 → 最近使用的函数」菜单改成运行时按记录生成，点一下插入 `=NAME()`。

三、界面实测（glow 构建，真实窗口循环 + 探针注入，不是纯单测）
--------------------------------------------------------------
命令：
  SC_WIZ_LOG=1 SC_CMD="6:InsertFunction" SC_TYPE="14:AVERAGE" SC_KEYSEQ="26:enter" \
  SC_SHOT=work/probe/ui114/wizard-apply3.png SC_SHOT_FRAMES=40 SC_SHOT_EXIT=1 \
  ./target/debug/app.exe work/probe/ui113/fixture.xlsx

探针日志（work/probe/ui114/wizard-apply3.log）：
  [keyseq] frame 26 -> enter
  [wiz] applied formula="=AVERAGE()" editing=Some(("=AVERAGE()", 9)) sel=(0, 0)
  [keyseq] 结束

说明：
  - 对话框实测矩形 620×449（[410,330]-[1030,779]），第一版因为 ScrollArea 继承了外层横向布局，
    475 行函数被排成一行，窗口宽 48893px、把整个网格盖白；改成显式 vertical + 330px 高的
    allocate_ui_with_layout 后尺寸稳定（wizard9.png 起）。
  - 搜索框输入 "AVERAGE" 后匹配数从 475 变成 5，并自动选中第一个匹配项（AVERAGE）。
  - 回车确定后 A1 进入编辑态：编辑栏显示 `=AVERAGE()`，格内编辑器显示同一串，光标停在括号里，
    状态栏「单元格模式 输入」「已插入函数 AVERAGE」。
  - 回归过一次：回车既被向导吃掉又被同一帧的格内编辑器当成「提交并下移」，
    导致 A1 被写成 0、选区跳到 A2。修法：确定时用 consume_key 把 Enter 从输入队列里拿走。
  - 真实用户目录的最近使用记录：%LOCALAPPDATA%\SheetsNative\fnrecent.txt
        AVERAGE
        SUM
    （向导点确定记一次，公式提交再记一次，MRU 顺序正确）
