日期：2026-11-14

一、四方向逐边（每本只点一条边，保存后 Excel 回读）
命令模板：
  SC_SEL="0,0" SC_CMD="20:Border<Dir>;60:FileSave" ... app.exe work/qa08/one-<dir>.xlsx
Excel Borders.Item: 7=左 8=上 9=下 10=右；1=细线，-4142=无。
结果：
  bottom: 左=-4142 上=-4142 下=1 右=-4142
  top:    左=-4142 上=1 下=-4142 右=-4142
  left:   左=1 上=-4142 下=-4142 右=-4142
  right:  左=-4142 上=-4142 下=-4142 右=1
结论：每个命令只落在目标边，保存重开仍保持；修复前 Bottom/Top/Left 写错下标的问题不再出现。

二、四边同时
命令：SC_SEL="0,0" SC_CMD="20:BorderLeft;30:BorderRight;40:BorderTop;50:BorderBottom;80:FileSave"
Excel 回读 A1：B7/B8/B9/B10 全部 LineStyle=1，Weight=2，Color=8421504（灰）。
结论：四边同时存在，颜色/粗细与实现一致。

三、外框 A1:B2
命令：SC_SEL="0,0" SC_SEL2="1,1" SC_CMD="20:BorderOuter;60:FileSave"
Excel 回读（左,上,下,右；True=有线）：
  A1=True True False False
  B1=False True False True
  A2=True False True False
  B2=False False True True
结论：只有外沿四边，内部横/竖线为空；B1:C1 的合并/边框不影响本项。

四、内部横线 A1:B2
命令：SC_SEL="0,0" SC_SEL2="1,1" SC_CMD="20:BorderInsideH;60:FileSave"
Excel 回读：
  A1=False False True False
  B1=False False True False
  A2=False True False False
  B2=False True False False
结论：只有 A1/B1 的下边与 A2/B2 的上边，外沿无框。
