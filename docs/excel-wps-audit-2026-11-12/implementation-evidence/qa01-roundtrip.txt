# QA-01.2 最小三方往返 runner

日期：2026-11-13（CST）
范围：QA-01 P0 的第二片；使用同一最小公式 fixture 跑三条要求路径，不把本片冒充 QA-01 父项完成。

## 入口

- core 往返 helper：`crates/core/examples/qa01_roundtrip.rs`
  - `load` → `formula::recalc_all` → `xlsx::save`
  - 不驱动 GUI，不打开用户文件；输出路径存在即拒绝覆盖。
- 三方 runner：`scripts/qa01_roundtrip.py`
  - 用 `DispatchEx` 为每一步创建独立 Office 实例。
  - 源应用先 `SaveAs` 到本次新建目录；core 输出由同一 runner 再交给目标应用只读打开。
  - 输入/输出 SHA-256、应用版本/build、核心 stdout/stderr、逐格差异全部写入 JSON。
  - 运行目录、fixture、manifest 都由参数指定；不覆盖已有文件。

## 实际执行

```text

  crates/core/tests/fixtures/qa01/qa01_formula_min.xlsx \
  C:/Users/Administrator/AppData/Local/hermes/cache/scratch/qa01_roundtrip_out.xlsx

python scripts/qa01_roundtrip.py \
  --fixture crates/core/tests/fixtures/qa01/qa01_formula_min.xlsx \
  --manifest docs/excel-wps-audit-2026-11-12/implementation-evidence/qa01-min-samples.json \
```

- 本次 runner 的 fixture 是 `.xlsx`；`.xls/.xlsm`、图表/图片/透视/打印/命名区域/
  隐藏冻结/外链等类别属于 QA-01.3 或父项剩余验收，尚未声称通过。
- 仅验证最小的公式/文本/错误/布尔/日期序列样本；没有覆盖修复提示、二次保存刷新、

- 三个 case 的源/目标应用都是 runner 自己创建的独立实例，未使用已有用户文档；
  这不等于 Excel/WPS 的人工目视矩阵。
