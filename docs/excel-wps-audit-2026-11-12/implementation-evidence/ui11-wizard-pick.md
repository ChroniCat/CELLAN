# UI-11：函数向导「拾取」把区域填进参数（2026-11-17）

Excel 的行为：向导开着时点表格里的区域，地址会直接进当前参数框。之前我们只能手打 `A1:B2`。

## 实现

- 每个参数行在输入框后面加一个 `拾取` 小按钮（输入框宽度 180→140 给它让位）；
- 点它后 `wiz_pick = Some(i)` 并记下 `wiz_pick_time = ctx.input(i.time)`，状态栏提示
  「在表格里拖选区域，松手后填进参数」；
- 之后任一帧若 `time > wiz_pick_time` 且 `pointer.any_released()`，用当前选区
  `(sel, sel_end)` 组成 `A1` 或 `A1:B2` 写进 `w.args[i]`，并清掉拾取态。

用时间戳而不是帧号：本项目的 egui 版本里 `Context` 没有 `frame_nr()`（编译期就报
`no method named frame_nr`），而 `InputState::time` 一直可用；`time > 设置时刻` 这一条同时
避免了「点拾取按钮那一下自己的松手」被误当成选区确认。

选区归一化抽成 `wiz_range_label(a, b)`，反向拖选（从右下往左上）也会得到 `A1:B3`。

## 验证

- `wiz_range_label_builds_a1_or_range`：`(0,0)`→`A1`、`(2,1)→(0,0)`→`A1:B3`、`(3,27)`→`AB4`（验证跨 Z 的列名）；
- app 全量 **361 passed**。
