# C17 条件格式的阈值类型、优先级与扩展保留

日期：2026-11-14 01:xx CST
审计基线：`CfRule` 无 priority；`parse_cf_blocks` 把 cfvo 一律折成 `Option<f64>`，
percent/percentile/num/formula 全丢；`overlay_at` 按 XML 顺序逐块求值，
块内还会重复遍历规则（本次一并修掉）；Dxf 只有字体/填充。

## 先用 Excel 校准（COM 写入 → 解包看 XML）

| ColorScaleCriteria.Type | 写出的 cfvo | 含义 |
| --- | --- | --- |
| 0 | `<cfvo type="num" val="50"/>` | 数值 50 |
| 3 | `<cfvo type="percent" val="50"/>` | 数据范围 50% 处 |
| 4 | `<cfvo type="formula" val="50"/>` | 公式 |
| 5 | `<cfvo type="percentile" val="50"/>` | PERCENTILE.INC 50 分位 |

（文档里常写的 4=percent 在本机 Excel 16.0 上是 formula，已按实测取值。）

## 实现

- `Cfvo { kind, val, formula }` + `CfvoKind`（min/max/num/percent/percentile/formula）；
  `resolve` 按块 min..max 与升序样本求阈值，percentile 用 `PERCENTILE.INC` 同款线性插值。
- `CfRule.priority` 原样解析/保存；`overlay_at` 变成**全局按 priority 升序**求值
  （同优先级按出现顺序），`stopIfTrue` 一旦命中直接结束，对同一 sqref 的多段范围同样有效。
- 保存时 priority 原样写回（缺省才补号），块与块内规则按 priority 升序输出，
  XML 顺序不再是求值依据。
- `Dxf` 增加 `num_fmt`（formatCode）与 `border`（style+color，四边同款）；
  overlay 增加 `border`，网格在填充之上画出来。
- `CfSheet.unknown_ext`：表里出现 `x14:conditionalFormatting`/extLst 时置位，
  条件格式管理窗口显示「未建模的扩展、保存会丢掉、无法无损编辑」。
- 条件格式管理里上移/下移/删除后按当前顺序重排 priority；打开文件时**不**重排，
  保证 Excel 给的 priority 原样往返。
- 顺带修：`quick_xml` 把 `&gt;` 发成 GeneralRef，此前公式型规则读进来会变成 `C10`
  （`>` 丢失），现在按实体还原。

## 真实夹具与 Excel 对拍

夹具 `crates/core/tests/fixtures/c17/priority.xlsx` 由 Excel 生成：
A 列三点色阶中点 percent 50；B 列 percentile 50；C 列两条同条件规则
XML 顺序 priority=8（红）→ priority=5（蓝）；D 列第一条 stopIfTrue。

Excel 导出的同区域图逐格取中心色（BGR 取整）：

| 格 | Excel 原始 | 本应用（SC_DUMP cf-fill） | Excel 重开本应用保存的文件 | 改 F1 后再保存 |
| --- | --- | --- | --- | --- |
| A1 1000 | (251,0,0) | [255,0,0] | (251,0,0) | (251,0,0) |
| A2 1100 | (251,0,0) | [255,1,0] | (251,0,0) | (251,0,0) |
| A3 100000 | (0,191,0) | [0,255,0] | (0,191,0) | (0,191,0) |
| B2 1100 | (251,250,0) | [255,255,0] | (251,250,0) | (251,250,0) |
| C1:C3 | (0,0,255) | [0,0,255] | (0,0,255) | (0,0,255) |
| D1:D3 | (255,0,0) | [255,0,0] | (255,0,0) | (255,0,0) |

A2 与 B2 同值不同色 → percent 50 与 percentile 50 确实分开；
C 列 XML 顺序与 priority 逆序，仍是 priority=5 的蓝色赢；
D 列第二条被 stopIfTrue 停掉。

保存往返后 Excel 读回的属性：

```text
A1:A3 count=1 priorities=3/stop=False   criteria types=1,3,2 vals=50   （percent 保住）
B1:B3 count=1 priorities=4/stop=False   criteria types=1,5,2 vals=50   （percentile 保住）
C1:C3 count=2 priorities=2,8            （Excel 归一化编号，蓝仍在前）
D1:D3 count=2 priorities=1/stop=True,2/stop=False
F1=123                                  （无关单元格修改）
```
