命令：cd scripts && python qa01_matrix_runner.py --out ../work/probe/qa01/matrix-full.json

一、跑法（三条路径）
--------------------
每个夹具：
  1. 原文件在 Excel 与 WPS 各取一份对象模型快照（真值）；
  2. `cargo run -p sheetcore --example pivot_roundtrip -- 源 副本`（只有 load+save）；
  3. 副本在 Excel 与 WPS 再各取一份快照；
  4. 逐字段 diff：只报差异，没有比对到的字段不算通过。
快照覆盖：工作表名/UsedRange、条件格式条数、数据验证条数、表格（名称+范围）、
名称（名字→引用，忽略我们的 `_sc_` 记账名）、页面设置（方向/纸张/缩放/打印区域/标题行列）、
冻结行列、隐藏行/列、图片数、形状（类型/名字/宽高/组合项数/SmartArt 节点数）、
图表（系列数/标题）、外部链接（按文件名比，路径随副本目录变）、透视表（字段+方向）。

四、这一轮 runner 自身修正的两个比对口径（都不是产品缺陷）
-----------------------------------------------------------
1) 外部链接按完整路径比 → 副本在别的目录，路径必然不同；改成按文件名比。
   实测 media.xlsx 源链接 `...\formats\ext-src.xlsx`、副本 `...\matrix\ext-src.xlsx`，
   文件名相同、公式目标一致。
2) 名称按位置比 → 我们保存时会追加隐藏记账名 `_sc_manual_hidden`，导致错位。
   改成按「名字→引用」字典比，并过滤 `_sc_` 前缀；同时补了 page setup 快照
   （manifest 里写了 page 类目就必须真读）。
