# UI-11.3 引用拾取 / F4 / 彩色引用

日期：2026-11-16
代码：`crates/app/src/main.rs`（`insert_reference`、`ref_spans`、`parse_ref_token`、`a1_end`、
`is_a1_ref`、`looks_like_ref`、`formula_layout_job`、`ref_color`、`pick_rect`、`EditState.caret/caret_override`）、
`crates/app/src/edit_regression_tests.rs`（4 条新用例）。

## 实现

| 原需求条目 | 实现 |
| --- | --- |
| 编辑 `=A1` 时点 B2 变成引用而非意外提交 | 按下格子的瞬间走 `insert_reference`：光标左侧若是引用/正在输入的引用就整段替换，否则在光标处插入；`pick_rect` 记录被引用格，鼠标松开帧不再提交、不改选区 |
| `A1 → $A$1 → A$1 → $A1 → A1` | 沿用上一轮的 `cycle_formula_ref`（F4 只循环缓冲末尾引用，函数名/数字不参与） |
| 公式里引用彩色显示 | `TextEdit::layouter` + `formula_layout_job`：按出现顺序取 Excel 风格四色（`#1F6FD0 / #1A8A3B / #8A3FB0 / #A15C00`），同一文本共用同色；`'My Sheet'!A1`、`Sheet2!$B$2`、`A1:B2` 都整段上色 |
| 文本中间 Alt+Enter 插入原光标处 | Alt+Enter 那一帧切多行 `TextEdit`，由 egui 按真实光标插换行（不再往缓冲末尾 push） |

要点：格内编辑与公式栏编辑共用同一个 `EditState.buf`，光标位置每帧从各自的 TextEdit
状态记回 `ed.caret`；补全/点选后通过 `caret_override` 把光标搬到新位置，否则后续输入会插进
函数名或引用中间（这是上一轮补全踩到的坑，本轮复用同一机制）。

- `ui113_insert_reference_matches_excel_pick_semantics`：`=A1` 点 B2 → `=B2`；`=SUM(` → `=SUM(A1`；
  `=A1+` → `=A1+B2`；`=SUM(A1` 点 C3 → `=SUM(C3`；`=SUM(A1:B2)` 光标在 `)` 前 → `=SUM(D4)`；
  `=A1` 光标在 `=` 后 → `=B2A1`。
- `ui113_ref_spans_colour_references_and_share_colour_per_text`：`=SUM(A1:B2)+A1*$C$3` 切出
  `A1:B2 / A1 / $C$3` 三段且不同色，`=A1+A1` 同色；非公式文本单段；带表名引用整段。
- `ui113_clicking_grid_while_editing_formula_inserts_reference`：真实 egui 指针按下+松开两帧
  （`click_grid`）后 `editing` 仍在、buf=`=A1+B2`、光标 6、`sel` 不动、`pick_rect=Some(B2)`，
  提交后 C1=13、细框清空。
- `ui113_textedit_layouter_keeps_ref_colours_in_galley`：`TextEdit` 输出的 galley 里确实带
  `#1F6FD0` / `#1A8A3B` 两段颜色（证明 layouter 生效，不是只算了个 job）。
- `ui113_alt_enter_inserts_newline_at_caret_not_at_end`：光标在 3 时 Alt+Enter → `=A1\n&B1`、光标 4。
