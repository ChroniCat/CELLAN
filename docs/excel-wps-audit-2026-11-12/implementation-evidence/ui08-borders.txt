UI-08.1 边框方向（2026-11-13 14:47 CST）

问题
- CellStyle.border 的真实顺序是左/右/上/下（xlsx 写 bs.set_left/right/top/bottom，
  绘制 0=左 1=右 2=上 3=下）。
- Ribbon 的 Bottom 写 [2]（上）、Top 写 [0]（左）、Left 写 [3]（下）；
  border_outer 同样把四方向写反，BorderInsideH/V 也用了错误下标。

实现
- core/style.rs 新增 BorderSide { Left=0, Right=1, Top=2, Bottom=3 } 与 idx()。
- ribbon/actions.rs：BorderBottom/Top/Left/Right、ThickBottom、DoubleBottom、
  InsideH、InsideV 全部改用 BorderSide，不再裸写下标。
- main.rs border_outer 使用 BorderSide：上/右/下/左分别写 2/1/3/0；已有
  outer_border 的 0/1/2/3 顺序保持一致。
- 未改格式对话框的混合样式提交逻辑；UI-08.2/08.3 仍待实施。

验证
- edit_regression_tests::ribbon_border_commands_follow_left_right_top_bottom_order：
  四方向各自只亮目标边；A1:B2 BorderOuter 只画外沿；InsideH 只画中间横线；
  InsideV 只画中间竖线。
- 命令：cargo test -p app --offline --bin app ribbon_border_commands_follow_left_right_top_bottom_order
  -> 1 passed。
- 全量：cargo test -p app --offline --bin app -> 214 passed / 0 failed / 0 ignored，
  APP_EXIT=0。

未完成
- 真实 Excel/WPS 打开保存后的四方向目视、格式对话框“不改直接确定”和混合样式
  （A1 红粗体/A2 蓝常规只改数字格式）仍未做；UI-08.1 保持待验收，父项不翻绿。
