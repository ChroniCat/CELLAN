# C07.1 命名列表 / 跨表区域 / 公式阈值

日期：2026-11-13 20:35 CST
范围：`crates/core/src/dv.rs`、`crates/app/src/main.rs` 的数据验证入口、合成夹具 `crates/core/tests/fixtures/c07/refs.xlsx`。

## 修复前

- `list_items` 只认内联 `"甲,乙"` 和本表 `A1:A2`；`=NamedList` 解析失败后返回空列表，
  `validate` 又把空列表当成“无限制”直接放行，非法文本能通过。
- `parse_bound` 只认数字和简单 `DATE(...)`；`=$A$1` 解析失败后按 0 比较，
  `>=` 规则会把 0 接受或把合法值误拒。
- 应用下拉开列表时同样只调用 `list_items`。

## 修复

1. 新增 `list_items_wb(wb, si, dv) -> Option<Vec<String>>`：
   - 解析工作簿级/表级命名区域（大小写不敏感，后定义优先）；
   - 解析跨表区域，支持 `列表!$A$1:$A$2` 与 `'Sheet Name'!A1:B2`；
   - 支持单值区域、内联逗号列表、`{"甲","乙"}` 字面量；
   - 无法解析返回 `None`，带工作簿入口按空列表拒绝，不再“全放行”。
2. 新增 `validate_wb`，把 `list_items_wb` 的结果注入校验；
   `validate` 保留给只有当前表上下文的调用者。
3. 数值 `TextLength/Whole/Decimal/Date/Time` 的上下界改走 `bound_value`：
   先试字面量/日期，再调用真实公式求值器；支持 `=$A$1`、命名区域、区域引用。
   求值失败返回 `false`，不再静默按 0 处理。
4. 应用的两处真实输入校验和下拉候选改用 `validate_wb` / `list_items_wb`。
