# UI-30.1 人工点击清单（14 个被跳过的功能区动作）

用途：这 14 个动作在无头环境里无法完成（原生文件对话框会阻塞、联网会等超时、共享会真起监听），
点击矩阵只做了「XML 里存在 + dispatch 有臂」的静态校验。**按本表逐条执行一次即可收口 UI-30.1**。

前置：启动 release GUI（`target/release/sheets.exe`，glow 构建），准备一份任意含数据的 `样例.xlsx`，
并准备一个测试图片（png/jpg）与一个 `导入.csv`。

判定口径：每一步只要「界面反应符合预期、程序不崩溃、状态栏提示合理」即通过；
若与预期不符，把实际现象记在「实际」列，不必改代码，交回即可。

## 附：为什么这些不能自动跑

- `rfd` 原生对话框会阻塞在没有桌面交互的会话里（`Start-Process` 都失败，见 `README-env-block.md`）；
- `Share/AutoShare` 会真起 TCP 监听，属网络副作用，不应在自动矩阵里静默执行；
- `CheckUpdate` 走网络，本机 keyless 后端连不通，会卡到超时（第一版矩阵就是这么卡住的）。

## 附二：动作 id 与按钮名的对应（已对 XML 机械核对）

| onAction | 按钮文字 |
|---|---|
| `FileOpen` / `FileSaveAs` / `FileSave` | 打开 / 另存为 / 保存 |
| `ExportPdf` | 导出 PDF |
| `ImportWorkbook` / `ImportCsv` | 导入工作簿 / 导入 CSV/TSV |
| `CompareBooks` | 并排比较… |
| `MacroExport` | 导出宏部件… |
| `InsertPicture` / `Hyperlink` | 图片 / 超链接 |
| `OpenInNewTab` | 打开到新标签 |
| `Share` / `AutoShare` | 共享 / 自动共享 |
| `CheckUpdate` | 检查更新 |

14 个 id 在 `customUI.xml` 里各存在至少一条 `onAction`（`Share` 2 条），无拼错/过期项。
