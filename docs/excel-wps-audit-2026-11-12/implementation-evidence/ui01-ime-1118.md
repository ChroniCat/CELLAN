# UI-01 / UI-01.1 真实键盘与中文输入法确认（2026-11-18）

## 环境

- 交互 RDP 会话 `rdp-tcp#0 Administrator 2 Active`。
- 真实物理注入：`SendInput(KEYEVENTF_SCANCODE)`（`wVk=0`）；不用 `SC_KEYSEQ`，不用内部直接调用 `commit_edit`。
- 工作簿：`work/probe/ui01_real.xlsx`（openpyxl 新建空白簿）、`work/probe/int_ime2.xlsx`（`c10/table.xlsx` 副本）。
- 输入法：本机 `HKCU\Keyboard Layout\Preload` 的 `00000804`（中文/微软拼音），app 线程 `GetKeyboardLayout` = `0x08040804`。

## 读数

### 1. 空白 A1 键入 123 Enter

物理扫描码 `0x02,0x03,0x04,0x1C`：

```text
名称框 = A2
编辑栏 = （空）
A1，123，已选中   （重新点 A1 读取）
```

A1 = 123，选区在 A2，Enter 只向下移动一格。

### 2. A1 F2 改 456 Tab

物理 F2 `0x3C`，Backspace `0x0E ×3`，`0x05,0x06,0x07`，Tab `0x0F`：

```text
名称框 = B1
B1，已选中
编辑栏 = （空）
A1，456，已选中   （回读 A1）
```

A1 = 456，Tab 提交并向右一格，未出现双重提交。

### 3. Esc 取消

A1 上 F2 后键入 789，按 Esc `0x01`：

```text
名称框 = A1
编辑栏 = 456
A1，456，已选中
```

Esc 丢弃未提交缓冲，原值不变。

### 4. 中文输入法确认（真实 IME）

`int_ime2.xlsx` 的 A1 选中后 F2 进入编辑，物理键入 `zhongwen` 的扫描码（z `0x2C`, h `0x23`, o `0x18`, n `0x31`, g `0x22`, w `0x11`, e `0x12`, n `0x31`）：

```text
编辑栏 = zhong'wen
单元格模式 = 输入
```

按 Space `0x39`：

```text
编辑栏 = 中文
```

按 Enter `0x1C`：

```text
名称框 = A2
A1 = 中文（保存后回读）
```

`xl/sharedStrings.xml` 含 `中文`；`sheet1.xml` 的 A1 为共享字符串索引 3。说明真实微软拼音候选已选中并提交，且 Enter 只把选区从 A1 移到 A2，未多跳。

### 5. 保存重开

`ui01_real.xlsx` 物理 Ctrl+S 保存，`Stop-Process app` 后重新启动同一路径：

```text
名称框 = A1
编辑栏 = 123
A1，123，已选中
```

保存/重开保持真实键盘写入结果。
