一、删除前的等价核对（逐项）
----------------------------
旧菜单四个函数（toolbar_notes / toolbar_view / toolbar_data / toolbar_page）删除前，
把它们「只在这里被调用」的实现列出来核对：

  export_macro_part → 已在上一轮接进审阅页签「宏」组（MacroExport）
  set_freeze        → 功能区 FreezeTopRow / FreezeFirstColumn / FreezePanes / Unfreeze
                      直接写 sheet.freeze + freeze_dirty，语义相同，旧函数可删
  export_pdf        → 功能区 ExportPdf → export_pdf_dialog，同样调
                      sheetcore::print::export_pdf_from，旧函数可删
  open_compare      → **功能区没有入口**（原来只在旧「页面布局」菜单里）→ 先补入口
  toolbar_cf 的快捷规则（突出显示/项目选取/数据条/图标集/色阶/清除）
                    → 功能区只有「新建规则…/管理规则…」，快捷规则没有入口 → 先补入口
  toolbar_dv 的圈释无效/清除验证 → 功能区只有「数据验证」编辑器 → 先补入口

------------------

   窗口调 items，功能区菜单仍调 toolbar_cf），不再套一层「条件格式」菜单。

   渲染 toolbar_dv_items（圈释无效数据、清除验证等）。
