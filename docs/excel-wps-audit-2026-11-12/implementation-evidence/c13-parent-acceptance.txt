# C13 父任务验收：保存子步骤失败必须阻止成功回执

## 覆盖矩阵

| 验收要求 | 证据 | 结果 |
|---|---|---|
| 注入保护失败 | `save_failure_injection` 步骤 `protection` | Err、点名步骤、原文件不变 |
| 注入图表失败 | 步骤 `chart-anchor` / `chart-refs`（带真实图表的合成基准） | Err、原文件不变 |
| 注入布局失败 | 步骤 `layout` | 同上 |
| 注入条件格式/数据验证失败 | 步骤 `cf-patch`（带 DV 的合成工作簿） | 同上 |
| 注入外链失败 | 步骤 `xlink-parts` / `xlink-cache`（带 ExternalBook） | 同上 |
| 注入宏补丁失败 | 步骤 `vba`（tests/data/real_macro.xlsm 副本） | Err、原文件哈希不变、解除后宏还在 |
| 原文件 SHA256 不变 | 每个注入用例都断言 | 通过 |
| dirty 保留 / 无成功提示 / 可定位错误 | app `failed_save_keeps_dirty_reports_the_step_and_allows_retry` | 状态栏「保存失败: 保存子步骤 layout 失败」、dirty=true、磁盘不变 |
| 修复故障后重试成功 | 每个用例最后都无注入保存一次并重开校验 | 通过 |
| 权限不足 | `readonly_target_is_not_silently_replaced`：只读目标文件 | Err（说明替换失败与临时文件位置）、原文件不变、半成品保留、清只读后重试成功 |
| 断电 | 不可模拟 | 未执行 |
| 文件被 Office 独占 | 与只读目标走同一条 rename 失败分支，但未构造真实共享冲突 | 等价路径已验证，真实独占未执行 |

## 保留差异与限制

- 断电无法在自动化里模拟；原子替换依赖同卷 rename（现有设计）。
- Office 独占锁未构造真实共享冲突；只读目标已验证同一失败分支（保留临时文件并如实报错）。
- 图表注入使用程序化插入的合成图表，不是 Office 造的复杂图表；复杂图表的部件保真属 C19/QA-01。
