`SC_DUMP` 证明粗体走富文本 run 路径且族解析到内嵌 700：


## 3. 行高与基线按字体度量

`crates/core/src/print.rs`：

```rust
pub fn cell_baseline(valign, top, ch, total_h, line_h, asc, desc) -> f32 {
    match valign {
        0 => top + ch - asc,                              // 顶对齐
        1 => top + ch - (ch - total_h) / 2.0 - asc,       // 垂直居中
        _ => top + desc + (total_h - line_h),             // 底对齐 + 多行
    }
}
```

`Out.vmetric: Option<Arc<dyn Fn(f32) -> (f32, f32)>>` 由 `Font::em_metrics()` 提供
（`ascender/upm`、`-descender/upm`），`draw_cell` 行高 = `asc + desc`，不再用
`size*1.18` 常数；未传 vmetric 时回退 `(0.92, 0.26)` 保旧行为。

测试（3 passed）：

```
cell_baseline_uses_font_ascent_and_descent
page_ops_honours_vmetric
pdf_embeds_real_bold_face_and_uses_it_for_bold_text
```

## 4. PDF 真粗体（不再描边）

`Doc.bold: Option<Font>` 写 5 个对象（`/F2` → Type0 `/Identity-H`、CIDFontType2、
FontDescriptor、FontFile2、ToUnicode）；粗体文本 `Tf /F2`，内容流无 `2 Tr` 描边。
字体流用 Flate 压缩，含两套 CJK 子集的单页 PDF 5.69 MB（未压缩 8.98 MB）。

实测（`work/probe/pdf_bold_demo5.pdf`（由 `pdf_bold_demo` 例程生成，不入库））：

```
F1 NotoSansSC-Regular /Filter /FlateDecode /Length1 4199028 decoded 4199028
F2 NotoSansSC-Bold    /Filter /FlateDecode /Length1 4103776 decoded 4103776
pdftotext -enc UTF-8 → "粗体标题 Bold 700 / 常规正文 regular 400 / 换行第一段…"
```

复现：

```bash
cargo build -q -p sheetcore --example pdf_bold_demo --offline -j 2
./target/debug/examples/pdf_bold_demo.exe work/probe/pdf_bold_demo5.pdf
pdftotext -enc UTF-8 work/probe/pdf_bold_demo5.pdf -
```
