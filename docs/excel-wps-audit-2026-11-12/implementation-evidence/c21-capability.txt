# C21.1 高级能力边界：命名、宏/线程批注保留、支持矩阵

日期：2026-11-14

## 1. 入口命名（不再是「按钮有了就算等价」）

| 位置 | 改前 | 改后 |
| --- | --- | --- |
| 功能区按钮 | 运行宏… | 用本机 Excel 执行宏… |
| 宏执行弹窗标题 | 运行宏（借助本机 Excel） | 用本机 Excel 执行宏 |
| 宏执行弹窗 | 仅「填宏名」 | 增加说明：本应用不内置宏引擎，只把宏名转交本机 Excel；不认识的宏不会自动运行 |
| 预测对话框 | 预测工作表 | 线性预测工作表 |
| 预测说明 | 最小二乘线性回归外推… | 追加「这是线性回归，不是 Excel 的 ETS/季节性预测」 |
| 快速填充对话框 | 快速填充 | 规则快速填充 |
| 快速填充状态栏 | 快速填充：规则（填了 N 格） | 规则快速填充：规则（填了 N 格；按已识别规则，不是通用程序合成） |

支持矩阵见 `docs/excel-wps-audit-2026-11-12/capability-matrix.md`
（宏：查看/保留 ✅、内置引擎 ❌、本机 Excel 执行 ⚠️ 显式；查询：导入 ✅、生成 queryTable ✅、
M/刷新 ❌；预测：线性 ✅、ETS ❌；快速填充：规则 ✅、通用合成 ❌）。

## 2. 未知宏不会被执行

- 应用加载只读单元格与结构，不解析/执行 VBA；`vba.rs` 只做 `read_vba`/`restore_vba`；
- 唯一执行路径是用户点「用本机 Excel 执行宏…」并填宏名，经 Excel COM `Application.Run`；
- 新加的弹窗文案明确这一点。

## 3. 含宏 / 线程批注的工作簿：改普通格保存后部件保留

夹具：

- `crates/core/tests/data/real_macro.xlsm`（既有，含 vbaProject.bin）
- `crates/core/tests/fixtures/c21/threaded_real.xlsx`：Excel 16.0
  `Range.AddCommentThreaded("这是一条线程批注")` 生成，含
  `xl/threadedComments/threadedComment1.xml`、`xl/persons/person.xml`、`xl/comments1.xml`

```text
cargo test -p sheetcore --offline -j 2 --test c21_parts -- --test-threads=2
threaded_comment_parts_survive_editing_a_normal_cell ... ok
vba_project_survives_editing_a_normal_cell ... ok
test result: ok. 2 passed
```

- 宏：改 B1 粗体后保存，`xl/vbaProject.bin` 与原文**逐字节相同**；
- 线程批注：umya 会把 `person.xml` 清空、重排 threadedComment 属性，甚至把
  `comments1.xml` 重写成普通批注镜像。保存尾部新增
  `fixups::restore_threaded_parts`：基准里存在 `xl/threadedComments/*` 时，
  连同 `xl/persons/*` 和 `xl/comments*.xml` 一起按原字节恢复；
- 测试断言三个部件逐字节相同，且工作表 rels 里仍有 threadedComment 关系。

两款 Office 回读我们保存的文件（`scripts/c21_verify_threaded.ps1`）：

```text
EXCEL: 打开成功，CommentThreaded 对象存在，B1='3.000' FMT='0.000'
WPS  : 打开成功，同上
```

（`CommentThreaded.Text` 在 COM 里是方法，PowerShell 直接取值打印出方法签名；
所以以「对象存在 + 部件逐字节一致 + 无警告打开」为准，不拿方法签名当文本。）

## 4. 查询表与 customXml（补充闭环）

`qtable::attach_csv` 生成查询表与 connections，再注入一个 customXml 部件，随后
加载、改 B1 斜体、保存：

```text
query_table_and_custom_xml_survive_editing_a_normal_cell ... ok
```

- `xl/queryTables/queryTable1.xml`、`xl/connections.xml`、`customXml/item1.xml`
  逐字节不变，工作表 rels 仍有 queryTable 关系；
- Excel 回读：`QT=1`（QueryTables.Count）、`CustomXMLParts.Count=3`（含注入项）、
  `B1ITALIC=True`；WPS 回读：`WPS_QT=1 B1ITALIC=True`。
