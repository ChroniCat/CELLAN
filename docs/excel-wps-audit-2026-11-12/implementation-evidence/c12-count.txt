# C12.1 透视计数空值修复

日期：2026-11-13 20:25 CST
范围：`crates/core/src/pivot.rs` 的 `compute` / `agg_value`。

## 复现的根因

`compute` 原来把每个源行都放进 `Vec<f64>`：数字 push 实际值，非数字（包括空格和文本）
在 `Agg::Count` 时 push `0.0`。于是：

- 组 A 的三行 `1`、`x`、空白，Count 得到 **3**；
- 空白格被当成数值 0 计数，文本 `x` 也被当成 0 计数；
- 文本无法与真正的空值区分。

## 修复

- 收集值改为 `PivotVal { n: Option<f64> }`；
- `Count` 只在源值非空时 push；空白（`Value::Empty` 或缺失单元格）不进入计数；
- `Sum/Avg/Max/Min` 仍只对可解析的数字计算（保留原有文本数字解析行为）；
- `Count` 直接返回非空条目数，不把缺失值折成 0。

## 20:43 监督指出的空组缺口

监督指出：把 `data.entry` 移进“非空/可转数”分支会让某个分组整组全空时标签消失。
已改为**先创建分组 entry，再决定是否纳值**；另外用本机 Excel 365 对拍全空组：

夹具：

- `Data!A1:B4`：`A/1`、`A/空`、`B/空`；
- Excel 创建 PivotTable，行字段 `组`，数据字段 `值` 的 `Function=xlCount (-4112)`。

实际读回（`cscript` late binding，Excel 16.0）：

```text
cell(2,4)=A      cell(2,5)=1
cell(3,4)=B      cell(3,5)=EMPTY
cell(4,4)=总计   cell(4,5)=1
pivot_rows=4
```

结论：Excel 保留全空分组 **B 的标签**，但 Count 单元格为**空白**，不是 0。
因此实现改为保留标签、空组 Count 返回 `Value::Empty`；单元测试断言
`B` 行存在且第二格为 `Empty`。
