# C12.1 透视计数空值修复

日期：2026-11-13 20:25 CST
范围：`crates/core/src/pivot.rs` 的 `compute` / `agg_value`。

## 复现的根因

`compute` 原来把每个源行都放进 `Vec<f64>`：数字 push 实际值，非数字（包括空格和文本）
在 `Agg::Count` 时 push `0.0`。于是：

- 组 A 的三行 `1`、`x`、空白，Count 得到 **3**；
- 空白格被当成数值 0 计数，文本 `x` 也被当成 0 计数；
- 文本无法与真正的空值区分。

## 修复

- 收集值改为 `PivotVal { n: Option<f64> }`；
- `Count` 只在源值非空时 push；空白（`Value::Empty` 或缺失单元格）不进入计数；
- `Sum/Avg/Max/Min` 仍只对可解析的数字计算（保留原有文本数字解析行为）；
- `Count` 直接返回非空条目数，不把缺失值折成 0。
