# UI-26 页面布局和打印设置的完整入口

日期：2026-11-14

## 已实现
- 统一“页面设置”对话框（`open_page_setup` / `page_setup_dialog`）：
  - 纸张：A4/A3/A5/Letter/Legal/Tabloid/Statement 明确选择；
  - 方向：纵向/横向；
  - 页边距：左、右、上、下、页眉、页脚，按毫米输入；水平/垂直居中；
  - 打印网格线/行号列标；
  - 缩放：百分比或“调整为 N 页宽 × M 页高”（0=自动）；
  - 打印区域：用当前选区/清除；顶端标题行、左侧标题列：用选区或当前行列；
  - 页眉/页脚文本；
  - 水平/垂直分页符分别插入、分别清除；
  - 打印：系统打印机列表（默认项带 `*`）、份数、全部/当前页/自定义页码、导出 PDF。
- Ribbon 的 `PageOrientation`/`PaperSize`/`PageMargins` 不再循环切换，统一打开该对话框做明确选择；
  原工具栏纸张/方向菜单保留，边距三套预设保留为快捷项。
- “插入分页符”改成 Excel 语义：在活动格左上同时插入水平+垂直分页；删除时同时删两侧。
- 预览实时响应：对话框修改先写入当前表 `page`（`apply_page_setup_draft`），预览/分页虚线立即按新设置重算；
  取消时用快照恢复 `page`、`page_dirty`、`wb.dirty`，不会把文档标脏。
- 打印页码范围：新增 `print::export_pdf_pages_from`，按 0 基闭区间只输出所选页；份数按份数提交打印任务；
  选择打印机用 `Start-Process -Verb PrintTo`，未选则系统默认。

## 验收实测
- **页面数基准**（同一夹具 `crates/core/tests/fixtures/c16/print.xlsx`，设置 A4 横向、左右 10mm、
  上/下 0.75in、首行重复、宽 1 页高自动）：
  - Excel 365 COM `PageSetup.Pages.Count = 2`；
  - WPS 12 COM `PageSetup.Pages.Count = 2`；
  - 本项目 `paginate` = 2；导出 PDF = 2（测试 `excel_style_page_setup_matches_two_pages`）。
- 取消/应用：`page_setup_cancel_restores_everything`；保存重开：`changes_survive_save`
  （print_area、title_rows、title_cols、row_breaks、col_breaks、margins）。
- 横纵分页：`manual_breaks_have_both_directions` 同时验证 x/y 断点；
  Ribbon 插入/删除两向：`ribbon_page_break_inserts_both_directions`。
- 入口语义：`ribbon_page_buttons_open_explicit_dialog`。
- 打印范围夹取：`print_page_span_modes_are_clamped`。
- 截图：`implementation-evidence/ui26/page-setup.png`；实测对话框包含全部控件和底部按钮。
