# UI-13.2：Ribbon 组内小图标二级压缩

原实现只有两级：整组完整显示 → 放不下时把整组塞进「组名 ▾」/「更多 ▾」，
缺少 Excel 的中间状态（大按钮压成 24px 小按钮、组内排 3–4 列）。本轮补上。

## 实现

`crates/app/src/ribbon/ui.rs`：

- `compact_leaf_count` / `compact_leaves`：跳过组内说明文字与空白，得到真正
  可点击的控件；`Box` 递归展开。
- `compact_width`：按控件数选 3/4 列，目标宽度上限 210px。
- `group_compact`：用 `allocate_ui_with_layout` 固定宽度，按 3/4 列分行渲染
  小按钮；大按钮统一改成 `Size::Normal`；组名仍在底部。
- 若该组有 `launcher`，走 `ui_kit::group_l`，右下角对话框启动器保留并仍能
  打开「设置单元格格式」。
- 触发顺序：整组放不下 → 若小图标网格能放下则先压缩；仍放不下才退化为
  「组名 ▾」/「更多 ▾」。首帧仍先画完整组，第二帧起稳定。
- 新增单测 `compact_alignment_group_has_a_bounded_grid`：Home「对齐方式」
  至少有 8 个命令，扁平化数量与计数一致，目标宽度在 72–210px 内。

## 渲染取证

用 `SC_WIN_W/SC_WIN_H` + `SC_ANIMATION_TIME=0` + `SC_SHOT` 抓帧，窗口尺寸
即内容尺寸；截图在 `implementation-evidence/ui13-2/`。

- `ribbon-760-home.png`：760×420，Home。剪贴板/字体保持完整；对齐方式变成
  两行小按钮网格，组名下仍能看到右下角启动器；右侧「更多 ▾」完整。
- `ribbon-760-formulas.png`：760×420，公式页。函数库的二级命令（逻辑/文本/
  日期和时间/查找与引用/数学和三角函数/其他函数）以小按钮网格出现，公式审核
  组完整；更多按钮在右边缘内。
- `ribbon-1024-home.png`：1024×768，Home；所有可见组完整，右边缘无裁切。
- `ribbon-1366-home.png`：1366×768，Home；样式组按小图标网格显示，单元格
  组与「更多 ▾」完整。

视觉核读（本机截图直接看，不是像素猜）：

- 760 Home：对齐方式命令全部可见，标签不重叠，启动器箭头在组右下角；
- 760 公式：函数库小按钮网格无重叠，更多按钮完整；
- 1024/1366：没有右侧裁切；更多按钮与右侧组不重叠。
