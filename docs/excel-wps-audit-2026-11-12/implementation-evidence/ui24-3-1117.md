# UI-24.3 验收证据：网格 UIA 选区语义（2026-11-17）

工具链：Windows UI Automation 客户端（PowerShell `UIAutomationClient`）直接读本程序
窗口，不靠截图、不靠目视。夹具 `crates/core/tests/fixtures/qa09/a11y.xlsx`
（A1:B2 合并、C3 冻结、第 6 行隐藏、D 列隐藏），由
`scripts/make_qa09_fixtures.py` 生成。

## 修前（旧二进制，`main` HEAD 之前的构建）

```
DataItem | A1，合并标题，已选中 | SelectionItem=N/A
parent=DataItem <- Window
```

- 活动单元格只有名字里带「已选中」，UIA 客户端拿不到 `SelectionItemPattern`，
  读屏软件无法查询 `IsSelected`。
- 整个网格是 `DataGrid`，但没有任何 `Grid` 的选区描述。

## 修后（当前构建，真实 UIA 读数）

选中 A1（合并区左上角、冻结区内）：

```
DataItem | A1，合并标题，已选中 | IsSelected=True
  HelpText=第 1 行，第 1 列，合并 A1:B2，冻结窗格内
  parent=DataItem <- Window <- Pane
GRID=工作表 无障碍，选区 A1:A1，1 行 1 列，活动单元格 A1
```

选中 A6（被隐藏的行）：

```
Name=A6，隐藏行，已选中
Help=第 6 行，第 1 列，冻结窗格内，隐藏行
Sel=True
```

行号/列标（`RowHeader`/`ColumnHeader`）同样暴露 `SelectionItemPattern`：

```
DataItem | 列 A，已选中 | SelectionItem sel=True
DataItem | 第 1 行，已选中 | SelectionItem sel=True
```

对应实现：

- `publish_grid_a11y`：活动格节点角色 `Cell`，写 `selected`、`row_index`、
  `column_index`、合并跨度 `row_span/column_span`；描述含
  「第 r 行，第 c 列」「合并 A1:B2」「冻结窗格内」「隐藏行/隐藏列」。
- 网格节点：`Grid` + `multiselectable`，名字给出工作表/选区/行列数/活动格。
- 单元格节点 id 按 `(工作表, 行, 列)` 固定，选区移动时旧节点消失、新节点出现，
  不再只有「可见范围内才重建」。

## UIA 适配层的本地补丁（vendor）

上游 `accesskit_windows 0.24.1`（egui 0.31 用的版本）只在
`Role::GridCell` 上暴露 `SelectionItemPattern`，而 accesskit 0.17 根本没有
`GridCell` 角色，只有 `Cell`；`RowHeader/ColumnHeader` 也不在列表里。因此：

- `vendor/accesskit_windows/`：从 crates.io 0.24.1 原样 vendoring（MIT/Apache-2.0），
  只改两处：
  1. `node.rs` 的 `is_selection_item_pattern_supported` 放行
     `Cell`/`RowHeader`/`ColumnHeader`；
  2. `adapter.rs` 的 `node_added`：新节点本身就是选中态时补发
     `UIA_SelectionItem_ElementSelectedEventId`（egui 的节点不会挂到 Grid 的
     children 里，容器 diff 派发不到这个事件）。
- 根 `Cargo.toml` 用 `[patch.crates-io]` 指到 `vendor/accesskit_windows`；
  `cargo tree -p accesskit_windows` 确认走的是 `F:\...\vendor\accesskit_windows`。

## 未能在本环境机检的一项

**UIA 事件回调**：本会话里连 `AutomationFocusChangedEventHandler` 都收不到任何
回调（对 Chromium 窗口 `SetFocus()` 同样为 0），说明不是事件代码单方面的问题，
而是当前无交互桌面会话不投递 UIA 事件。因此「选区变化发 ElementSelected」这条
只做到**代码路径 + 适配层补丁**，没有观测证据，不写成已验收。

复现脚本：`work/probe/uia_a11y_check.ps1`、`uia_count.ps1`、
`uia_events.ps1`（事件订阅，本环境 0 回调）、`uia_focus_events.ps1`（对照）。
