# QA-06.2 迭代计算/循环引用：现状核查（2026-11-17）

## 结论

本引擎**没有迭代计算能力**，不是「没测」，是「没有实现」。

机械核查：

```
grep -rn "circular|iterat" crates/core/src/formula/mod.rs           -> 0 命中
grep -rn "Iterative|iteration" crates/core/src crates/core/src/formula -> 0 命中
```

`formula::recalc_all` 走依赖图拓扑序，环上的节点没有迭代分支，也没有
「最大迭代次数 / 最大变化量」这两个 Excel 参数。

## Excel 侧口径（待对拍时按此建夹具）

Excel 的迭代计算在「文件 → 选项 → 公式」里，对应对象模型：

```powershell
$xl.IterativeCalculation = $true
$xl.MaxIterations = 100          # 默认 100
$xl.MaxChange = 0.001            # 默认 0.001
```

典型收敛例：`A1 = B1 + 1`、`B1 = A1 / 2` → A1=2、B1=1（100 次内收敛）。
关闭迭代时 Excel 对环返回 0 并弹警告，本引擎当前行为需要单独测。

## 为什么没在本轮做掉

这不是补一条用例，是给求值器加一个新阶段：
1. 依赖图要能识别强连通分量（现在拓扑排序遇到环直接判错）；
2. 环内节点要按 Excel 的「上一轮值」语义反复求值，直到 `max|Δ| <= MaxChange` 或达 `MaxIterations`；
3. 增量重算要保证「环外依赖环」的单元格在收敛后再取一次值，否则增量与全量不一致；
4. 还要把 `IterativeCalculation/MaxIterations/MaxChange` 落到工作簿设置（calcPr 的 `iterate/maxIterations/maxChange`），并在 UI 里可改。

四项都做完才能说这条验收通过，半途写个「最多跑 100 次」的循环只会得到和 Excel 不一致的数。

## 台账处理

QA-06.2 的 not_done 保留这一条，并改写为可执行口径（见 implementation-progress.json）：
需要实现迭代计算 + calcPr 往返 + 增量一致三件事，而不是「补测」。

## 2026-11-17 追加实测：引擎对环的行为

`A1 = B1+1`、`B1 = A1/2` 在 `formula::recalc_all` 之后：

```
thread 'circular_pair_converges_like_excels_iteration' panicked:
不是数字：Error(Circular)
```

即引擎在 `Calc` 里对环返回 **`ErrKind::Circular`**，没有「上一轮值」的迭代语义；
即使外面套了 `passes = formula_count + 1` 的多遍扫描，环上的格子也始终是错误值。

Excel 同一对公式（迭代开启、MaxIterations=100、MaxChange=0.001）收敛到 `A1=2`、`B1=1`。

轴点就在 `Calc::cell_value` 的环判定处：迭代开启时不能直接返回 Circular，
而要取「上一次求值结果」（首轮取 0，Excel 口径）继续算，直到 `max|Δ| <= maxChange`
或达到 `maxIterations`。用例已写成 `#[ignore]`，实现后去掉 ignore 即为验收开关。

## 2026-11-17 收口：迭代求解器已通

三处改动（`crates/core/src/formula/mod.rs`）：
1. 环判定分叉：`calc_iterate` 时返回「上一轮值」（空/错误按 0，Excel 首轮口径）；
2. 多遍循环的提前退出条件加 `!calc_iterate` 守卫——环上没有溢出，原条件第一遍就 break，
   导致「100 遍」形同虚设（实测 A1 停在 1、B1 停在 0）；
3. 循环末尾按 `CYCLE_CELLS` 记的格子算 `max|Δ|`，小于 `calc_max_change` 即收敛退出；
   同时收尾清理不再把环上格子改写成 `Circular`（那是「不稳定」口径，不是迭代口径）。

实测（`A1=B1+1`、`B1=A1/2`、`calc_iterate=true`、默认 100 次 / 0.001）：

```
[calciter] A1=1.9990234375 B1=0.9990234375
test result: ok. 3 passed
```

Excel 同参数收敛到 `A1=2`、`B1=1`，差值 9.77e-4，落在 `MaxChange=0.001` 内。
