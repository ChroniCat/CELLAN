C02 数组形状与二维广播
======================
日期：2026-11-13 UTC+08   对标：core-requirements.md C02（C02.1/C02.2/C02.3）
本机 Excel 16.0 与 WPS 均保留二维/纵向数组形状，`=SUM({1;2}+{10,20})` = 66。

一、原缺陷（先复现，红线输出）
------------------------------
需求点名的三行，修复前实测：

    =SEQUENCE(2,2)+1        →  (1, 4, "2,3,4,5")      期望 (2, 2, "2,3/4,5")
    =SEQUENCE(3,1)*2        →  (1, 3, "2,4,6")        期望 (3, 1, "2/4/6")
    ={1;2}+{10,20}          →  (1, 2, "11,22")        期望 (2, 2, "11,21/12,22")
    =SUM({1;2}+{10,20})     →  33                     期望 66
    =SEQUENCE(3,1)>1        →  (1, 3, "false,true,true") 期望 (3, 1, "false/true/true")
    =SUMPRODUCT({1,2;3,4},{1,1,1,1}) → 10             期望 #VALUE!

根因两处（与需求定位一致）：
- `operand_values` 把区域/数组一律摊平成 `Vec<FValue>`，形状信息在这里就丢了；
- `eval_binary` 只比元素个数，结果固定 `Array::new(1, n, out)`，所以纵向数组必被写成横的；
  2×2 与 1×4 元素个数相同也被当成「等长」放过。

二、改动
--------
1. `formula/mod.rs` 新增 `operand_block(&Node) -> (rows, cols, Vec<FValue>)`：
   区域用 `Arg::Range{rows, cols}`，数组用 `Array{rows, cols}`，标量视作 1×1。
2. `eval_binary` 改成按两个维度分别匹配/广播：
   - 行列都相等 → 逐格算；
   - 某一边该维为 1 → 复制（3×1 + 1×4 → 3×4，真正的二维外积式广播）；
   - 其余 → `#VALUE!`（2×2 + 2×3、2×2 + 1×4 都拒）。
3. 一元负号与百分号同样走 `operand_block` 逐元素映射（`=-SEQUENCE(2,2)`、`=SEQUENCE(2,1)%`）。
4. `SUMPRODUCT` 改为按 (rows, cols) 校验：标量 1×1 可参与，其余必须同形，否则 `#VALUE!`。
5. **溢出区被用户覆盖时的数据保护**（本轮连带修的真实缺陷）：
   `Sheet::set` 现在会把被写的格子从 `spilled` 集合里摘掉；
   `clear_spills` 只清还在 `spilled` 里的格子。于是用户往溢出区里打字后重算：
   用户内容保留、锚点变 `#SPILL!`（Excel 语义），不再被 `clear_spills` 静默吞掉再按数组值覆盖。

三、用例 `crates/core/tests/array_shape.rs`（11 项）
---------------------------------------------------
| 用例 | 断言 |
|---|---|
| `a_2x2_array_plus_scalar_keeps_its_shape` | `=SEQUENCE(2,2)+1` → 2×2 `2,3/4,5` |
| `a_column_array_times_scalar_stays_a_column` | `=SEQUENCE(3,1)*2` → 3×1 `2/4/6` |
| `a_column_plus_row_broadcasts_to_the_full_rectangle` | `{1;2}+{10,20}` → 2×2 `11,21/12,22`；`SUM` = 66 |
| `matching_shapes_multiply_elementwise` | 2×2+2×2、标量+3×1、3×1+1×4（3×4 全 12 格值逐个断言） |
| `incompatible_shapes_are_a_value_error` | 2×2+2×3、2×2+3×2 → `#VALUE!` |
| `comparison_and_concat_keep_the_operand_shape` | 比较与 `&` 拼接保留 3×1 / 2×1 |
| `unary_minus_applies_to_every_element` | `=-SEQUENCE(2,2)` 2×2、百分号 2×1 |
| `sumproduct_requires_matching_shapes` | 同形 = 10；2×2 与 1×4 → `#VALUE!` |
| `filter_uses_the_condition_shape_not_its_length` | 列条件 `FILTER(A1:A5,A1:A5>2)` → 3×1；行条件 → 1×3 |
| `spill_anchor_shape_downstream_and_blocking` | 锚点 A1=2、B1=3、A2=4、B2=5；下游 `SUM(A1:B2)=14`；占住 B2 → `#SPILL!` 且输入「挡」保留；移开后形状回来 |
| `the_spilled_shape_survives_a_save_and_reopen` | 存盘只落锚点公式（子格为空），重开后 `recalc_all` 恢复 2/3/4/5 |
