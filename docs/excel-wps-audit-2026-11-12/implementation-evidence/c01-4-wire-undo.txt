C01.4 wire/undo 兼容与端到端
=============================
日期：2026-11-13 UTC+08   对标：core-requirements.md C01（切片 C01.4）

一、要证明的事
--------------
模型加了 `Value::Error` 之后，错误值必须能原样穿过三条会「序列化/快照/回填」的路径：

1. 协作同步：`Op` → JSON（网线上就是这个）→ 远端 `Peer::apply` → 写回工作簿；
2. 撤销/重做：`CellDelta.before/after` 是整格 `Cell`，撤销要连公式一起还原；
3. 整表快照：结构性改动用 `SheetSnapshot` 回填。

同时不能把「看起来像错误的文本」在途中变成错误值（反向也要成立）。

二、实现位置（无新增逻辑，验证迁移是否完整）
--------------------------------------------
- `sync.rs`：`ValueWire::Error(String)`，`From<&Value>` / `From<&ValueWire>` 用
  `ErrKind::text()` 与 `ErrKind::from_text()` 互转；`#[derive(Serialize, Deserialize)]`。
- `undo.rs`：`CellDelta { before: Cell, after: Cell }`、`snapshot_sheet`/`restore_sheet`
  都是整格克隆，错误类型随 `Cell` 走。
- `revision.rs`：`Snap` 的类型标记新增 `"x"`（错误），`to_cell` 用 `from_text` 还原。

三、用例
--------
`crates/core/tests/error_wire_undo.rs`（5 项）

| 用例 | 断言 |
|---|---|
| `an_error_op_survives_json_and_applies_as_an_error` | `#DIV/0!` 操作经 JSON 往返后 `ValueWire::Error`，远端应用后模型里是 `Error(Div0)`，公式 `=1/0` 也在 |
| `text_that_looks_like_an_error_stays_text_on_the_wire` | 文本 `#DIV/0!` 过线仍是 `Text` |
| `last_writer_wins_between_an_error_and_a_value` | 错误与数值互有胜负，胜出的一侧类型正确（两个方向都测） |
| `undo_and_redo_restore_the_error_cell_verbatim` | 撤销回 `Error(Div0)` 且公式 `=1/0` 回来；重做回 `Number(1.0)` |
| `sheet_snapshot_roundtrips_error_cells` | 整表快照回填后错误与「像错误的文本」各自保持 |

`crates/app/src/edit_regression_tests.rs::app_undo_restores_an_error_cell_after_a_real_edit`（1 项）
走 App 自己的 `txn_begin`/`txn_end`/`do_undo`，不是直接构造 core 的撤销栈。

`the_network_envelope_carries_the_error_type`（第 6 项）测的是 `net.rs` 真正发包用的那一层：
`serde_json::to_string(&Msg::Op(op))` → `Msg` 反序列化 → `Peer::apply` → 工作簿。
与只测 `Op` 相比，这一层把 `Msg` 信封（含 `Cursor`/`Lock*` 等枚举变体）的 serde 也覆盖了。

四、变异验证（真实输出）
------------------------
把 `ValueWire` 的错误分支退回「当文本传」（`from` 侧 `Error → Text`，`to` 侧 `Error(t) → Text`）：

    test an_error_op_survives_json_and_applies_as_an_error ... FAILED
      left: Text("#DIV/0!")   right: Error("#DIV/0!")
    test last_writer_wins_between_an_error_and_a_value ... FAILED
      left: Text("#REF!")     right: Error(Ref)

恢复后 5 项全过。

五、还没做（如实保留）
--------------------
- **真实双进程 socket 传错误值**没有 GUI 级取证：现有双进程框架（`other_participant_lock`）
  证的是锁消息与端口/单实例隔离，错误值只证到 `Msg::Op` 信封 + `Peer` 状态机 + 模型应用。
- 未与 Excel/WPS 实机对拍。
