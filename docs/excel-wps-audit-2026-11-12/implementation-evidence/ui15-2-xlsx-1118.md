# UI-15.2：.xlsx 逐格锁定语义（Excel COM 实测）

前一轮只对 `.xls` 做过逐格锁定（XF bit0）；`.xlsx` 一直是
「只有样式 roundtrip，没有让 Excel 真的按 locked 位拒绝/放行」。本轮补上。

## 夹具

`crates/core/tests/fixtures/c15/protected.xlsx`（本机 Excel 16.0 创建）：

- A1：`CellStyle.locked=true`，公式隐藏；
- B1：`CellStyle.locked=false`，是输入区；
- 工作表保护标签：`<sheetProtection sheet="1" formatCells="0"/>`（无口令）。

## 实测 1：原文件在 Excel 里写

`work/probe/c15_xlsx_edit.ps1`，只读打开后改值：

```
readonly_src=False protected=True
A1_write=DENIED  err=您试图更改的单元格或图表位于受保护的工作表中…
B1_write=EDIT_OK
B1_value=INPUT2
```

即 Excel 认可 A1 锁定、B1 未锁定，和我们的样式模型一致。

## 实测 2：经本程序 load→save 后再用 Excel 写

`qa01_roundtrip.exe` 把 `c15_protected_edited.xlsx` 纯文件往返为
`c15_protected_rt.xlsx`（1 表，6.7KB），再用 `c15_xlsx_check.ps1` 打开：

```
sheets=1 protected=True B1=INPUT2
A1_write=DENIED
```

- 保护标签仍在；
- B1 的编辑值（INPUT2）保留；
- A1 仍被 Excel 按 locked 位拒绝。

## 结论与剩余

`.xlsx` 的文件级逐格锁定语义已用 Excel 16.0 COM 双向验证，不再只是
「XML 里有 locked 属性」。UI-15.2 仍待验收的部分只剩：真实鼠标在
“设置单元格格式→保护”页勾选/确定/取消、Excel/WPS 重开后的对话框目视；
这些属于无交互桌面的阻塞项，不写成通过。
