## 19:54 CST 监督二项修正

1. **数组夹具去掉循环引用**：原 `array.xlsx` 在 B2:D2 写
   `=SUM(A2:C2)`，B2 同时是输出左上格和输入区域成员，样本本身是循环的。
   生成器现只写 A2:C2 输入，数组输出改到 **B4:D4**，公式 `=SUM(A2:C2)`；
   测试锚点/区域断言相应改为 `(3,1)`/`(3,1,3,3)`，仍保留
   `t="array"` 与 `ref="B4:D4"` 的 XML 断言。
   重生成后的 `array.xlsx` SHA-256
   `a88898e4a4c72438069efead1163e93c9979341761d2cd8f8eaa2c219d05fe38`。
   实际测试：
   `cargo test -p sheetcore --offline --test array_formula` -> 2 passed,
   0 failed, 0 ignored。该样本只证明标记/锚点/区域可读写，**不声称**
   该工作簿的缓存计算结果正确，也不把它当公式语义证据。

2. **page_setup 删除无关清理**：`changes_survive_save` 原先会
   `remove_file("tests/test-work/page_edit2.xlsx")`，该文件不是本测试生成，
   默认执行会删不相关文件。该行已删除；只保留本测试 PID 产物
   `page_out_<pid>.xlsx` 的清理。重跑 page_setup -> 3 passed, 0 ignored。

上述两处是夹具/测试卫生修正，不改变父项状态，也不把 QA-02.1 记为完成。
