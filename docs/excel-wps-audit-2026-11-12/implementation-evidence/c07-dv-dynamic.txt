## 监督指出的缺口（属实）

1. `list_items_wb` 见到 `(` 就返回 None，把真正的动态列表和带括号的工作表名一起拒了；
   旧测试还把这个 None 当成"通过"，等于没有动态列表实现。
2. `list_items_wb` 没有目标 r/c，来源区域不按规则范围锚点平移：
   C2:C3 用 `=$A1:$A2` 时 C3 仍看 A1:A2。

## 用本机 Excel 核对的真实语义

脚本 `scripts/excel_dv_source_probe.ps1`（新建隐藏 Excel 实例，不碰用户文档），实测输出：

```text
REL C2==$A1:$A2 C3==$A2:$A3 val30=True val10=False
DYN formula==OFFSET($A$1,0,0,COUNTA($A:$A),1) val30=True val99=False
NAME formula==动态表 val20=True
PAREN formula=='预算(2026)'!$A$1:$A$2 val乙=True
INDIRECT formula==INDIRECT("主表!A1:A2") val20=True
```

结论：
- 数据验证的 Formula1 按**规则范围左上角**为基准，每个单元格看到的是平移后的公式
  （C2 是 `$A1:$A2`，C3 是 `$A2:$A3`），且 C3 只接受 A3 的值。
- OFFSET 动态来源、指向 OFFSET 的名称、INDIRECT 文本区域都可用。
- `'预算(2026)'!$A$1` 里的括号在引号表名内，是合法引用，不是函数调用。
- 信息级提示按钮是"确定/取消"（Excel UI 语义，另见 c07-dv-styles.txt 的修复记录）。

## 实现

`list_items_wb(wb, si, dv, r, c)` 现在是唯一入口：

1. 内联 `"甲,乙"`。
2. 裸名称逐层展开（本表级优先，其次工作簿级，最多 8 层），名称目标可以是区域或公式。
3. 按 `range_anchor` 取本格锚点，用 `cf::shift_formula(expr, r-ar, c-ac)` 平移整条来源
   （字符串字面量不会被平移，和 Excel 一致）。
4. 静态区域：`split_sheet_prefix` 只认**引号外**的第一个 `!`，表名按 `''` 反转义；
   `parse_rect` 支持 `A1`/`A1:B2`/`A:A`/`1:1`，行号溢出按非法处理（不再退化成整列）。
5. 动态：
   - `INDIRECT("表!A1:A2")`（文本不再平移，Excel 同）；
   - `OFFSET(锚点, 行, 列[, 高[, 宽]])`，参数支持字面量与
     `COUNTA/COUNT/ROWS/COLUMNS(区域)` 及 `+ - * /` 组合；
   - `FILTER(区域, 区域<>"")` —— 现代 Excel 最常用的动态列表写法，空白不进候选；
   - `UNIQUE(来源)`、`SORT(来源[, 索引, 方向])`。
   - 其它数组函数（如带条件的 FILTER、SUMPRODUCT）仍返回 None → 配置错误，
     不猜、不用数组字面量冒充。

整列区域（`A:A`）用 `Sheet::iter()` 稀疏遍历，不逐格扫 1048576 行。

## 对旧行为的纠正

- `=A999999999999999999999` 之前会解析成"整列 A"并返回空候选（等价放行）；
  现在行号溢出直接判非法引用 → 配置错误。
- 中文名称前缀切片曾 panic（`t[..name.len()]` 落在多字节字符中间），
  改成 `t.get(..n)` 后按字节边界安全返回。
