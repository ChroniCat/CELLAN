# 优先级与可执行任务索引

这是唯一优先级与依赖表，正文分组不覆盖这里的决定。所有任务为待实施，源码风险必须先复现。S=单一有界改动，M=2个关联切片，L=至少3个切片或跨模型改动；不是承诺工期。每次只实现一个切片，继承父任务的现状、对标要求与验收，不允许一次领取整批L任务。切片可单列优先级：UI-27.3连续格式刷是P2，不阻断该父任务的P0数据安全验收。

## 第一批建议顺序

QA-03.1隔离环境 → UI-01修复输入提交 → UI-02.1保存快捷键 → C13.1保存失败注入 → C03公式字符串 → C01.1错误类型回归 → C22常规对齐 → UI-10关闭/页签。C04日期体系与C06序列60/本地时钟分别实现，不互为硬依赖；两项共享转换函数时必须保留对方回归。UI-13可在核心任务之间独立推进，但不要并行修改同一main.rs。

现有测试通过不替代新增缺陷验收。QA-01/02为分阶段基准建设，不要求先一次建完所有高级样本才能开始修复；每个修复必须携带自身失败样本。
