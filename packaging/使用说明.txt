CELLAN 使用说明
================
Concurrent Engine for Local-first, Lock-free Async Networks

版本：1.70

系统要求
--------
- Windows 10 / 11，64 位（x64）。
- 自动适配 OpenGL 3.3 硬件加速与 DirectX 12 / WARP 软件渲染，普通台式机/笔记本、
  云桌面、虚拟机及无 3D 加速的远程桌面均可直接打开；若遇异常退出，
  诊断日志位于 %LOCALAPPDATA%\CELLAN\crash.log。
- 无需安装 Office，也不需要 .NET / VC++ 运行库（已静态链接）。

使用
----
- 双击 CELLAN.exe 即可，免安装、单文件；设置和最近文件写在
  %LOCALAPPDATA%\CELLAN（首次升级会自动迁移旧目录配置），不会在程序所在目录生成额外文件。
- 在资源管理器双击多个表格文件会自动并入同一窗口的多标签页；重复双击已打开文件会自动
  切换并唤醒原窗口；可在“文件 → 设为默认应用”一键关联 .xlsx / .xlsm / .xls / .csv 打开方式。
- 右上角账户按钮可以修改本机显示名称；协作光标、编辑占用和修订记录都用
  这个名字。默认名带计算机名，避免多人共用 Administrator 时显示成同一个人。
- 支持 .xlsx / .xlsm / .xls / .csv；保存保持 Excel 兼容格式。
- 协作走共享盘或局域网，不需要服务器，也无需设置房间口令：多人打开共享盘、局域网共享文件夹或同步盘里的同一份工作簿时，会自动静默连线，实时看到彼此的光标位置、编辑锁定与单元格改动；同一单元格同一时间只允许一个人编辑。
  未走共享目录时，也可在“局域网实时协作”面板一键开启共享，其他同事输入地址直接加入。首次共享时 Windows 防火墙可能会弹一次允许提示。
- 内置 AI 表格助手（右上角“AI 助手”或按 Ctrl+Shift+A）：预设企业本地 DeepSeek 接口
  且内置密钥受保护（不向配置文件写入明文密钥），支持自然语言读写单元格、编写填充公式与
  排查错误。可按轮撤销已记录的表格编辑，后续在其他单元格的独立修改会保留。
  修改重叠时请按顺序撤销。新建或重命名工作表会重置撤销历史。自定义配置位于 %LOCALAPPDATA%\CELLAN\ai.ini。

首次运行提示
------------
- exe 没有代码签名，Windows SmartScreen 可能提示“Windows 已保护你的电脑”，
  点“更多信息 → 仍要运行”即可。杀毒软件误报时添加信任。

更新（可选）
------------
默认不联网检查更新。可在「检查更新」里选一个共享发版目录，目录里放
manifest.txt（version / exe / sha256 三行）。发现新版本时只提示版本号和位置，
不会自动下载或替换程序（共享目录可写时，自动安装会被人借来分发恶意程序）；
请向管理员索取正式安装包手动更新。不配就完全离线。
